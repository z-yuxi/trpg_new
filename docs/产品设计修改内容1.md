## 二、给程序员的沟通话术

> 以下话术可直接用于与开发团队的沟通（IM、邮件或会议）。

### 标题：GM 控制台设计调整说明（混合模式）

**背景**  
当前 GM 控制台采用顶部折叠面板设计，在实际使用中发现以下问题：
1. 面板高度仅 200-240px，轨迹矩阵、场景连通编辑等功能完全无法正常使用。
2. 6 个标签页挤在狭窄空间，GM 需要在“看聊天”和“操作管理”之间频繁切换视线，体验割裂。
3. 移动端不得不采用底部动作表单分页，与桌面端逻辑不一致，增加维护成本。

**决策**  
经过讨论，将 GM 控制台改为**混合模式**：
- **高频操作**（时间推进、审批、快速扮演）保留在聊天界面顶部栏。
- **复杂功能**（场景管理、NPC 管理、线索库、轨迹矩阵、网格地图）进入独立全屏管理页面。

**对现有代码的影响评估**  
| 模块 | 现状 | 改动方式 | 预估工作量 |
|------|------|----------|------------|
| 时间推进（+30m 等） | 已在折叠面板内 | 移到顶部栏，复用逻辑 | 0.5 天 |
| 审批移动列表 | 已在折叠面板内 | 改为独立模态框，复用表格组件 | 0.5 天 |
| NPC 快速扮演 | 已在折叠面板内 | 改为独立模态框，复用列表 | 0.5 天 |
| 场景管理页面 | 部分在折叠面板 | 新建独立页面，复用现有表单/表格 | 1 天 |
| NPC 管理页面 | 部分在折叠面板 | 新建独立页面，复用现有组件 | 1 天 |
| 线索库页面 | 部分在折叠面板 | 新建独立页面，复用线索列表 | 1 天 |
| 轨迹矩阵页面 | 仅入口 | 新建独立页面，完整实现表格（如已有则直接复用） | 0.5 天 |
| 网格地图页面 | 可能已有独立实现 | 只需添加入口链接 | 0 天 |
| 路由配置 | 无 | 新增 `/campaign/:id/gm/*` 路由 | 0.2 天 |

**总计约 4-5 人天**，可分两阶段实施：
- Phase 1（2 天）：顶部栏快捷操作 + 审批/NPC 模态框 → 解决最痛点
- Phase 2（2-3 天）：独立管理页面（场景、NPC、线索、轨迹矩阵）

**重要原则（请务必遵守）**  
1. **以现有已实现的功能为优先**。如果某个功能已经完成且运行正常，不要为了“匹配文档”而重构。本文档仅作为未来调整的参考。
2. **严禁硬编码示例名称**。代码中不得出现如“黑暗边缘团”、“波士顿图书馆”等固定字符串。所有团名、场景名、NPC 名必须从后端数据动态获取。
3. **路由参数必须使用真实的 `campaign_id`**，不可写死测试 ID。
4. 若发现文档描述与现有实现冲突，请及时反馈，我们会同步更新文档，**不要求强行修改已有代码**。
