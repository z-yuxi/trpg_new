## N01.1 职责边界

本附录负责：

1. 用户协议、隐私政策、侵权投诉与内容审核标准。
2. 版权存证、内容分级、未成年人提示与举报处置要求。
3. 平台作为内容服务平台的法定义务与最小落地口径。

本附录不负责：

1. 注册登录、Token、后台权限与部署。
2. 业务安全、掷骰可信、引擎沙箱。
3. 社区信誉分与处罚等级细则。

## N01.2 合规能力清单

| 功能 | 核心要求 | MVP 落地 |
| --- | --- | --- |
| 用户协议 | 注册时必须同意，更新后需重新确认 | 协议文本版本化存储 |
| 隐私政策 | 页面底部可随时查看，支持删除账号说明 | 15 天冷静期 |
| 侵权投诉 | 提供在线投诉表单，48 小时内初步响应 | 投诉记录落库 |
| 内容审核 | 人工审核时效 <= 3 个工作日 | 审核记录表保留 reviewer_type |
| 版权存证 | 发布/更新模组时自动计算 SHA-256 哈希并触发时间戳存证 | 模组叙阅器页展示存证状态 |
| 内容分级 | 绝对红线 + 16+ 允许区间 + 越界拦截 | content_rating 枚举 |
| 未成年人保护 | 注册提示与内容标识，不额外采集出生日期 | 房间/模组显示 16+ 标识 |

补充口径：作品阅览保护统一由叙阅器执行，包括溯源水印、复制限制、PDF 导出限制与版权声明自动嵌入；这些机制属于权益保护与合规展示，不直接等同于侵权裁决结果。

## N01.3 内容安全责任

平台作为网络信息内容服务平台，至少承担以下义务：

| 责任项 | 具体要求 | MVP 方案 |
| --- | --- | --- |
| 实名制管理 | 发布信息前完成手机号认证 | 手机号验证码注册 |
| 违法信息处置 | 涉政、涉黄、涉恐等违法信息立即删除 | 举报 + 人工审核 + 严重者封号 |
| 用户举报机制 | 提供便捷举报入口并及时处理 | 每条消息旁保留举报按钮 |
| 主动巡查 | 对公开内容定期抽查 | 公共内容平台抽查，私团由 GM 辅助管理 |
| 配合监管 | 保留必要日志并配合调取 | 聊天日志至少保留 6 个月 |
| 未成年人保护 | 不向未成年人提供不适宜内容 | 标注 16+ 与注册弹窗提示 |

补充口径：

1. 昵称创建与修改必须经过敏感词过滤。
2. 聊天内容 MVP 不自动替换文本，但必须支持举报与后续审查。
3. 内容审核开关、敏感词词库与 review_status 字段需预留后台配置能力。

## N01.4 侵权投诉与下架流程

### 投诉受理

1. 任何用户可通过模组/规则包叙阅器页提交侵权投诉。
2. 投诉材料包含身份信息、权利证明与侵权证据。
3. 平台在 48 小时内完成初审，材料齐全时可先行下架。
4. 明确作者认领为特殊投诉渠道：在原有投诉入口（举报按钮）之外，增加“版权认领与侵权申诉”入口。作者认领提交后，作为高优先级侵权投诉处理。
延长缓冲期至7个自然日：作者认领后，平台进入“协商缓冲期”，时限为7天（168小时），取代原有48小时下架时限。在此期间，相关模组暂时隐藏，双方可通过站内信沟通。
封存而不物理删除：若作者最终选择下架，平台执行“应作者要求已封存”状态，从公开列表隐藏。已获取该模组的用户不受影响。此作为平台履行“通知-删除”义务的标准操作。

### 认领缓冲期（特殊流程）

1. 作者认领提交后，平台进入**协商缓冲期**，时限为 **7 天（168 小时）**，取代原有 48 小时先行下架时限。
2. 缓冲期内，相关社区版模组暂时隐藏（不可公开搜索），双方可通过站内信沟通协商。
3. 作者须在 7 天内选择处理方式：**保留**（模组转为已授权状态继续公开）或**下架**。

### 封存机制

1. 若作者选择下架，平台执行"**应作者要求已封存**"状态，从公开列表隐藏，不执行物理删除。
2. 已获取该模组的用户不受影响，可继续正常使用。
3. 贡献者的贡献记录与积分不因封存而消失。
4. 此操作作为平台履行"通知-删除"义务的标准操作程序。

### 申诉机制

1. 被投诉方可在 7 天内提交申诉与原创证据。
2. 申诉成功恢复上架；失败或逾期则永久下架并记录违规。
3. 恶意投诉同样计入违规记录。

### 处罚措施

- 累计 3 次侵权违规，账号永久封禁，已售收入冻结。
- 恶意投诉累计 3 次，同样封禁。

## N01.5 版权存证口径

1. 模组发布或更新时自动计算哈希值。
2. 通过司法区块链或等效可信时间戳服务生成 proof_id、proof_time、proof_url。
3. 存证证书可作为侵权申诉与原创证明的证据材料。
4. 模组叙阅器页必须展示版权存证状态，但不应把存证等同于侵权裁决结果。
5. 叙阅器中的溯源水印、复制限制、PDF 导出限制与版权声明自动嵌入，属于平台的版权保护辅助机制；命中或绕过这些机制本身不直接构成侵权裁定结论，仍需结合投诉材料与人工审核判断。

## N01.6 内容分级与提示

1. 违法、色情、侵权、诈骗等属于绝对红线，直接下架。
2. 常规暴力、恐怖题材可在 16+ 范围内存在，但需明确标识。
3. 平台仅履行告知与标识义务，不以采集生日等重型手段扩大个人信息收集。

## N01.8 同人创作与知识产权保护

### N01.8.1 IP 策略匹配引擎（S1–S4）

平台维护 `ip_rules` 数据库，对主要商业 IP 标注策略类型，在模组发布流程中自动匹配处置逻辑。

| 策略 | 名称 | 适用特征 | 典型案例 |
|:---|:---|:---|:---|
| S1 | 封闭保护型 | 版权方明确禁止一切同人，或频繁维权 | 迪士尼、任天堂 |
| S2 | 有条件开放型 | 有明确二次创作指引，允许免费但有内容限制 | Project Moon、TYPE-MOON、东方 Project、米哈游 |
| S3 | 默许无政策型 | 无公开同人政策，但长期默许同人生态 | 大量动画委员会制日漫、弹丸论破 |
| S4 | 开放授权型 | 提供创作许可/开放游戏许可/社区授权 | COC 7th、D&D SRD |

### N01.8.2 各策略处理规则

| 策略 | 发布时系统行为 | 公示期行为 |
|:---|:---|:---|
| S1 | 弹出阻止提示，强烈不建议发布；作者须额外勾选"我了解风险，仍要发布"方可继续 | 标记高风险，优先人工复核 |
| S2 | 弹出合规提醒弹窗，展示 `ip_rules.summary` 字段内容；作者确认后继续 | 人工复核队列正常优先级 |
| S3 | 弹出强制声明输入框，要求作者手动填写创作声明（最少 20 字） | 正常流程 |
| S4 | 正常流程，提示"建议注明授权来源" | 正常流程 |
| 未命中 | 提示"该 IP 暂无收录规则"，引导创作者提交官方指引链接/摘要 | 正常流程 |

### N01.8.3 IP 规则数据库 Schema

```sql
CREATE TABLE ip_rules (
  id           VARCHAR(64)  PRIMARY KEY,
  ip_name      VARCHAR(128) NOT NULL,
  policy_type  ENUM('S1','S2','S3','S4') NOT NULL,
  summary      TEXT         NOT NULL COMMENT '二次创作指引摘要，用于 S2 弹窗展示',
  official_url VARCHAR(255),
  last_updated_by ENUM('platform','creator','community') DEFAULT 'platform',
  last_updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  status       ENUM('active','pending_review','outdated') DEFAULT 'active'
);
```

### N01.8.4 IP 入库优先级（P0，首批约 15–20 个）

| 优先级 | IP 类别 | 说明 |
|:---:|:---|:---|
| P0 | TRPG 规则系统（COC、D&D、Pathfinder 等） | 平台核心内容，必须首批入库 |
| P0 | 国内高活跃度同人 IP（东方 Project、Type-Moon 系、Project Moon 系） | 创作者数量最多，规则最明确 |
| P0 | 米哈游旗下 IP（原神、崩铁等） | 已有官方同人政策，需严格按 S2 入库 |
| P1 | 主流日漫/动画 IP（按月活创作者数量排序） | 逐步入库，S3 为主 |
| P1 | 国内严格维权 IP | 标记为 S1，优先配置阻止提示 |

### N01.8.5 AI 辅助监控策略

| 能做的事 | 不能做的事 |
|:---|:---|
| 定时扫描已知官方页面，检测同人政策文本变更 | 实时对每个新发布的模组进行合规判断 |
| 对 S3 类 IP 公开信息进行自动抓取，生成变更提醒 | 代替版权方解释其政策的适用范围 |
| 辅助管理员检索维权历史新闻与公告 | 在发布时直接判定"合法/非法" |

### N01.8.6 规则更新机制

| 方式 | 频率 | 负责方 |
|:---|:---|:---|
| 高优先级 IP 人工定期检查 | 每季度 | 运营团队 |
| 社区/创作者反馈 | 随时 | 作者提交，管理员审核 |
| AI 辅助监控 | 持续 | 定时抓取 + 变更提醒 |

### N01.8.7 平台绝对红线

任何模组，无论同人声明如何，均不得包含以下内容，一经发现立即下架并封停创作者资格：

1. 直接复制官方设定集、剧情 PDF、游戏内文本连续超过 **200 字**。
2. 使用官方美术资源作为模组核心素材，且未获授权。
3. 以同人名义进行任何形式的收费或商业推广。
