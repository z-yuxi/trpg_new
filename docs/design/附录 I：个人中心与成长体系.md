本附录负责：

## I.2 页面定位与布局

定位：用户身份、关系、消息和偏好设置的统一管理中心。资产发现归“探索”，已获取内容归“团途-个人馆藏”，本附录聚焦“团途”。

布局：左侧导航 + 右侧内容区，统一复用后台型 PageLayout。

### 左侧导航

1. 个人主页编辑
2. 通知
3. 私信
4. 关注/粉丝
5. 账号设置
6. 创作者后台入口卡片，仅创作者可见，点击后跳转 H02 对应后台页

### 右侧默认页：个人主页编辑

- 头像：支持上传并裁切为 1:1 圆形。
- 昵称：2-16 字符，命中敏感词禁止提交。
- 简介：100 字以内纯文本。
- 身份标签：展示 player、gm、creator，其中 creator 由审核结果驱动，不可手动自选。
- 隐私设置：高光墙可见范围、私信可达范围。
- 公开主页预览：新窗口打开 /u/{uid}。

#### 编辑展示面板（个人名片区块）

在「团途」→「编辑展示」面板的「个人名片」区块，新增设置项：

| 设置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 展示创作者身份标签 | 开关 | 关 | 开启后，小名片与个人主页展示「创作者」标签；关闭后仅展示「玩家」/「GM」标签。 |

交互规则：

1. 仅创作者可见此开关，非创作者不展示。
2. 开关关闭时，在房间、招募帖、小名片、个人主页中不展示「创作者」标签。
3. 开关开启时，「创作者」标签与其他身份标签并列展示。
4. 无论开关状态如何，创作者后台（/creator）始终可访问，不受影响。

与匿名/笔名发布关系：

1. 该开关仅控制身份标签展示。
2. 模组发布时的匿名/笔名是独立维度，二者互不影响。

## I.4 私信

布局：左侧会话列表 + 右侧聊天区。

规则：

1. 支持文字、图片、引用回复与举报消息。
2. 新私信搜索排序固定为 UID 精确匹配 > 昵称前缀匹配 > 昵称模糊匹配。
3. 无会话时展示空状态，不静默留白。
4. 私信权限受用户隐私设置控制。

---

## I.5 关注与粉丝

- Tab：我的关注 / 我的粉丝。
- 用户卡片展示头像、昵称、简介、互关标识。
- 支持关注、取消关注、移除粉丝。
- 点击卡片跳转对方个人主页。

---

## I.6 账号设置

### 账号安全

- 手机号展示与更换入口。
- 密码设置入口，留空表示仅验证码登录。
- 登录设备管理为后续迭代入口。

### 内容偏好

- 规则偏好：COC 7th、D&D 5E、Pathfinder 等。
- 题材偏好：恐怖、奇幻、科幻、悬疑等。
- 推荐算法开关：关闭后仅基于热门内容推荐。

### 主题

- 浅色 / 深色 / 跟随系统。

### 数据管理

- 导出我的数据。
- 删除账号，保留 15 天冷静期。

### 页脚合规信息

首页页脚固定展示：备案号、联系我们、协议入口。个人中心不重复承载该信息块。

## I.7 成长体系预留

V1.0 只定义字段与展示骨架，不开放完整玩法。

### 建议字段

```sql
ALTER TABLE users ADD COLUMN exp INT UNSIGNED NOT NULL DEFAULT 0;
ALTER TABLE users ADD COLUMN level TINYINT UNSIGNED NOT NULL DEFAULT 1;
ALTER TABLE users ADD COLUMN badge_ids JSON;
ALTER TABLE users ADD COLUMN growth_flags JSON;
```

### 预留能力

1. 等级：反映活跃度与平台成长，不直接授予会员权益。
2. 徽章：活动、创作、社区贡献等荣誉标识。
3. 成长任务：新手引导、创作者任务、社区贡献任务。
4. 横幅提示：忽略为会话内不再提示，关闭仅临时隐藏。

## I.8 空状态与边界

| 场景 | 显示内容 |
| --- | --- |
| 无通知 | SVG 占位图 + 暂无通知 + 去社区 |
| 无私信会话 | 暂无私信 + 查找用户 |
| 无关注/粉丝 | 去社区发现有趣玩家 |
| 非创作者点击创作者后台 | 提示尚未成为创作者并引导申请 |

边界说明：

1. 模组、规则包的发现归「探索」标签；已获取作品（资产）归「团途」→个人馆藏；两者均不归个人中心主体。
2. 创作者后台是跳转入口，不是个人中心子 Tab 的完整承载页。
3. 会员等级与成长等级不是一套体系，前者见附录 H01，后者只表达活跃成长。
