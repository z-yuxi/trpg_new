
# 附录 J：移动端适配设计指南

> **文档版本**：v1.5  
> **核心原则**：功能不减、交互重塑、手势优先、渐进增强  
> **平台**：PWA（可安装至桌面），需支持 iOS Safari 和 Android Chrome

> **2026-04-25 对齐说明**：本附录遵循 `docs/文档对齐治理.md` 中定义的统一优先级与冲突处理规则。规则工坊能力按规则配方方案执行，文中出现的“L3 画布”统一替换为“Recipe 编辑器（表单/DSL）”。

## 一、整体布局适配

| 元素 | 桌面端 | 移动端 |
|------|--------|--------|
| **底部导航** | 5个文字+图标（高度48px） | 5个图标+隐藏文字（长按显示标签），高度56px，触摸热区≥44px |
| **页面内边距** | 24px | 16px |
| **卡片/网格** | 多列响应式（4列→2列） | 默认2列，列表项高度≥56px |
| **筛选栏** | 多行横向排列 | 顶部显示2-3个主要筛选项，其余折叠入“更多筛选”底部抽屉 |
| **模态框** | 居中弹窗（宽≤500px） | 全屏底部抽屉（可从下滑关闭），圆角顶部16px |

### 1.1 创作者后台移动端布局基线

创作者后台（仪表盘、素材库、我的作品、规则工坊）移动端必须复用 PageLayout 框架，不允许页面各自实现。

| 桌面端（已重组） | 移动端规范 | 说明 |
|---|---|---|
| PageLayout（Header + Stats + FilterBar + Content） | 垂直堆叠：Header（吸顶）→ Stats → FilterBar → Content | 统一信息层级，避免页面分裂 |
| Stats 4 列网格 | 2 列 x 2 行卡片网格 | 卡片高度一致，数字优先 |
| FilterBar 与内容并排 | FilterBar 位于 Stats 下方，横向滑动 + 抽屉二级筛选 | 首屏只保留高频筛选项 |
| 内容区卡片网格 | 默认单列；仅当视口宽度 >= 390px 且卡片最小宽度 >= 168px 时切换双列 | 卡片标题、状态、更新时间三段式 |
| 主操作按钮 | 按 1.1.1 规则自动选择 Header 右上角或 FAB，不下沉到底栏 | 保持与桌面端入口语义一致 |

#### 1.1.1 主操作按钮放置规则（移动端）

为避免长标题挤压按钮，主操作按钮采用双模式：

| 场景 | 按钮位置 | 示例 |
|---|---|---|
| 标题短（<=4 字）且单一主操作 | Header 右上角 | 素材库 + 上传素材 |
| 标题长、说明文本存在或需要双按钮 | 使用浮动 FAB | 创作者仪表盘 + 管理模组/进入规则工坊 |

**FAB 规范（采用 FAB 时必须遵守）**：
- 位置：`right: 16px; bottom: 72px`（避开全局底部导航）。
- 尺寸：`56px x 56px`，圆形。
- 色值：`background: var(--color-primary)`，图标白色。
- 交互：点击展开动作菜单（新建模组/新建规则集/上传素材）。

#### 1.1.2 FilterBar 结构与二级筛选规范

移动端 FilterBar 统一结构：固定显示 2-3 个高频项 + 更多筛选入口 + 搜索入口。

```plain
[全部] [草稿] [已发布] [更多筛选 ▼] [🔍]
```

点击“更多筛选”后，底部抽屉必须包含：
1. 状态筛选。
2. 规则包筛选（如页面适用）。
3. 排序方式。
4. 操作区（重置 / 应用筛选）。

各页面高频筛选项统一如下：

| 页面 | 固定显示 | 抽屉内 |
|---|---|---|
| 仪表盘 | 无 FilterBar | 无 |
| 素材库 | 全部 / 图片 / 音频 | 排序（上传时间 / 名称 / 大小） |
| 我的作品 | 全部 / 草稿 / 已发布 | 审核中 / 已弃用 + 规则包筛选 + 排序 |
| 规则工坊 | 全部 / 我的 / 已发布 | 规则包类型 + 排序 |

## 二、跑团房间移动端专属布局

跑团房间是移动端最复杂的页面，需重新设计为**底部快捷栏 + 抽屉面板**模式。

```
┌─────────────────────────────────┐
│ [←] 房间名     👥3  ☀️ [GM] [≡] │ ← 顶部栏（汉堡菜单、GM控制台入口）
├─────────────────────────────────┤
│ [剧情场] [私密场] [公共场]        │ ← 聊天场Tab（可横向滑动）
├─────────────────────────────────┤
│                                 │
│  聊天消息区（气泡）               │
│  - 普通消息：左/右气泡            │
│  - 骰子结果：卡片样式             │
│  - 线索揭示：卡片，点击展开        │
│                                 │
├─────────────────────────────────┤
│ [输入框]                    [📎]│ ← 输入区
├─────────────────────────────────┤
│ [🎲] [角色卡] [指令] [更多]       │ ← 底部快捷栏（固定4个按钮）
└─────────────────────────────────┘
```

**底部快捷栏功能**：
- `[🎲]`：展开骰子快捷面板（预设常用指令，如 .ra 侦查、.r 1d100）
- `[角色卡]`：弹出半屏抽屉，显示当前角色卡摘要（头像、姓名、HP条、核心属性），点击“编辑”展开完整角色卡表单
- `[指令]`：弹出半屏指令速查列表，点击指令自动填入输入框
- `[更多]`：弹出底部动作表单，包含“投骰历史”、“切换身份”、“退出房间”等

**顶部栏右侧按钮**：
- `[GM]`（仅GM可见）：打开GM控制台（底部动作表单，分页展示）
- `[≡]`：打开左侧导航抽屉（场景列表、轨迹矩阵精简版、在场角色）

### 2.1 房间功能映射（桌面 Ribbon -> 移动端）

桌面端顶部 Ribbon 的功能项在移动端必须有明确映射，不允许“未定义入口”。

| 桌面端功能项 | 移动端入口 | 备注 |
|---|---|---|
| 场景 | 顶部场切换 Tab（剧情场/私密场/公共场） | 维持当前设计 |
| NPC | `[更多]` -> `NPC` 抽屉 | 只读查看与快捷跳转 |
| 线索 | `[更多]` -> `线索` 抽屉 | 支持查看与筛选 |
| 笔记 | `[更多]` -> `笔记` 抽屉 | 支持基础文本编辑 |
| 骰子 | `[🎲]` 快捷面板 | 保留常用指令与快捷投掷 |
| 配置工具栏 | `[GM]` 与 `[≡]` | GM 操作和导航入口 |

### 2.2 双底栏切换规则

| 场景 | 显示规则 |
|---|---|
| 在跑团房间内 | 显示房间底部快捷栏（`[🎲] [角色卡] [指令] [更多]`），隐藏全局底部导航 |
| 在创作者后台/社区/我的页面 | 显示全局底部导航，隐藏房间底部快捷栏 |
| 房间返回非房间页 | 底栏在路由切换完成后替换，不做并存显示 |

### 2.3 移动端创作台入口规则（2026-04-27 修缮）

> **历史方案（参考）**：曾讨论在底部导航新增"创作台"第 6 项。已废弃，底部导航固定 5 项。

- 移动端**不新增**底部导航项；创作台入口通过以下两条路径可达：
  1. **顶栏图标**：`MainLayout` 顶栏右侧（返回键右侧区域）当用户为创作者时显示 `icon-workshop` 图标，点击进入 `/creator`；
  2. **个人页首屏卡片**：`Personal.vue` 中在用户信息卡与 Stats 卡之间插入高优先级"创作台"入口卡片（带品牌色边框）。
- 两条路径均在用户信息加载中时不显示（骨架态），避免"先隐藏后闪现"。
- 触控目标尺寸≥ 44×44px，满足移动端规范。

## 三、关键组件移动端行为

| 组件 | 桌面端行为 | 移动端适配 |
|------|------------|------------|
| **左侧导航（场景列表）** | 固定侧边栏（240px） | 汉堡菜单 → 滑出半屏抽屉（宽度85%），点击项后关闭 |
| **右侧助理台** | 固定侧边栏（320px） | 移除固定面板，功能移至底部快捷栏（见上文） |
| **GM 导演模式（全屏管理页面）** | 左侧情境导航（200px）+ 右侧内容区 | 全屏模态（从底部滑出，高度 ≥ 90vh）；顶部横向可滚动 Tab 切换情境；内容区垂直滚动；轨迹矩阵改为时间轴卡片视图；场景连通图/NPC 完整表单显示"请在电脑上操作"提示 |
| **叙事模式顶部栏快捷操作** | 显示 `[+30m]` `[+1h]` `[审批(N)]` `[导演台]` | 保留 `[审批(N)]` `[导演台]` 图标；时间推进 `[+30m]` `[+1h]` 移入导演模式"此刻"面板顶部 |
| **内联线索发放浮层** | 底部输入区 `[线索]` 按钮弹出浮层 | 点击后底部弹出选择器（线索列表 + 接收者列表），滑动选择 |
| **时间推进预演抽屉** | 顶部滑下预览面板，列出将触发的预约移动 | 改为底部动作表单，展示待执行列表，大按钮确认 |
| **轨迹矩阵（完整版）** | 灰白分区表格，横向+纵向滚动 | **改为时间轴视图**（见第四章） |
| **网格地图（Token移动）** | Canvas拖拽Token | **降级为静态地图+坐标列表移动**（见第四章） |
| **规则工坊 Recipe 编辑器** | 表单/DSL 编辑与模板选择 | 不可用，提示“请在PC端编辑”，移动端只读查看已发布规则配方 |
| **模组编辑器（文档式块）** | 块编辑器 | 移动端可编辑元信息（标题、描述、标签、状态）、纯文本段落与标题层级（H1/H2/H3）；复杂组件块只读；图片/音频仅查看；保存后与桌面端近实时同步 |
| **可视化拖拽编辑器（日志导出）** | 拖拽排序场景块 | 不可用，提示“请在PC端使用”，移动端仅支持基础导出（TXT/Markdown） |

## 四、会员专属功能的移动端适配

### 4.1 轨迹矩阵（会员功能）

**桌面端**：横向时间轴 + 纵向场景列表，单元格显示角色头像，支持点击查看快照。

**移动端适配**：改为**时间轴视图 + 场景筛选**

- **默认视图**：垂直时间轴，按时间倒序排列，每条节点显示：
  - 时间（如“第1日 15:30”）
  - 该时刻发生的场景切换事件摘要（如“张三 进入 图书馆”）
  - 可点击展开查看该时刻所有场景的角色位置快照（以卡片列表展示）
- **场景筛选**：顶部下拉选择特定场景，时间轴只显示该场景的角色位置变化。
- **GM操作**：长按时间节点弹出动作菜单（强制移动、调整时间），不支持单元格拖拽。

**技术实现**：使用虚拟滚动列表渲染时间轴，快照数据按需加载。桌面端的表格视图仍保留，移动端自动切换为时间轴（响应式判断 `max-width: 768px`）。

### 4.2 网格地图（会员功能）

**桌面端**：Canvas网格，支持拖拽Token、上传底图、多图层。

**移动端适配**：降级为**静态地图预览 + 坐标列表移动**

- **默认视图**：显示当前场景的地图缩略图（图片），不可拖拽Token。
- **角色位置**：地图旁显示角色列表，每个角色后跟坐标（如“A3”）。
- **移动操作（仅GM）**：点击角色 → 弹出简化网格列表选择器（选择目标格子） → 确认后更新位置。
- **可选高级模式**：用户可开启“精细模式”（提示性能消耗），使用Canvas网格并支持双指缩放、单击选中角色后点击网格移动（非拖拽）。

**技术实现**：地图数据存储为图片+网格配置（行列数、格子尺寸）。移动端默认只读，编辑操作通过表单完成。高级模式需用户主动开启。

## 五、手势与触摸规范

| 手势 | 用途 | 适用场景 |
|------|------|----------|
| **点击** | 选中、打开、提交 | 所有按钮、卡片、列表项 |
| **长按（≥500ms）** | 打开上下文菜单 | 房间卡片（管理）、消息（举报）、时间轴节点（GM操作） |
| **左滑** | 删除/归档 | 通知列表、私信会话 |
| **右滑** | 返回上一页 | 全屏抽屉、详情页 |
| **双指缩放** | 放大查看 | 地图、图片、复杂图表（如轨迹矩阵时间轴） |
| **下拉刷新** | 刷新列表 | 招募板、动态、消息列表 |

> **注意**：避免与系统手势冲突（如iOS左滑返回）。在边缘区域保留系统手势。

## 六、性能与体验优化

| 优化项 | 策略 |
|--------|------|
| **懒加载** | 聊天消息按需加载（每次20条），滚动顶部加载更多；轨迹矩阵时间轴虚拟滚动 |
| **网络不稳定** | WebSocket自动重连，断线时显示顶部横幅“连接中...”，重连后拉取缺失消息（通过 `missed_messages` 事件） |
| **后台保活** | PWA使用Service Worker缓存静态资源；跑团房间心跳保持（每30秒ping），但移动端允许后台断开，重连后同步 |
| **资源压缩** | 地图图片自动压缩为WebP，头像使用CDN且尺寸自适应（?x-oss-process=image/resize,w_200） |
| **触感反馈** | 关键操作（发送消息、掷骰、创建房间）使用轻震动（仅Android，需用户授权） |

### 6.1 模组编辑跨端同步规则

1. 移动端可编辑范围：元信息（标题、描述、标签、状态）、纯文本段落、标题层级（H1/H2/H3）。
2. 自动保存防抖：移动端 1.5 秒无输入触发保存；桌面端保持 3 秒。
3. 强制保存触发：点击完成、路由离开、切后台时必须立即触发一次保存，不等待防抖。
4. 冲突提示策略：桌面端正在编辑时收到移动端更新，仅显示非阻断 Toast（3 秒自动消失），提供“刷新查看”和“稍后处理”。
5. 用户未刷新继续编辑时，以下次保存返回的版本冲突提示为准，不强制中断当前输入流。
6. 资源级订阅频道：
  - 模组变更频道：`/modules/{module_id}/changes`
  - 规则包变更频道：`/rulesets/{ruleset_id}/changes`（预留）
7. 频道按资源订阅，不按用户广播；客户端仅订阅当前打开资源。
8. 离线队列：可编辑内容先写入 IndexedDB，再尝试保存；失败进入指数退避重试；恢复前台后自动重试；成功后清理缓存并推送变更事件。
9. 保存请求应带 op_id 做幂等去重，避免弱网重试导致重复写入。

## 七、移动端功能降级原则

移动端对部分桌面端复杂功能采用降级策略，核心原则如下：

|功能类型|降级方式|基本要求|
|---|---|---|
|**规则工坊 Recipe 编辑器**|只读查看|保留查看入口，所有编辑控件统一隐藏，提示请在电脑上使用此功能|
|**模组编辑器（文档式块）**|轻量可编辑|开放元信息、纯文本段落、标题层级编辑；复杂组件块（NPC 卡/线索卡/场景属性/骰子指令）只读；图片/音频仅查看|
|**可视化日志编辑器**|完全禁用|移动端不提供入口；通过其他入口访问时统一提示请在电脑上使用此功能|
|**空间操作工具**（网格地图、轨迹矩阵）|简化交互|将拖拽/画布操作改为表单/列表选择；核心数据可查看并通过受控入口修改|
|**场景连通配置**|只读查看|移动端仅查看路径列表，编辑入口统一引导至 PC|
|**数据可视化图表**（创作者后台统计图）|降级为表格|用纯数字表格替代图形化图表|

**通用交互要求**：

- 禁用功能点击时，使用 Toast 提示引导至 PC 端，文案统一为“请在电脑上使用此功能”。
    
- 只读视图需保留核心信息展示，不得因降级导致数据丢失或不可见。
    
- 简化交互模式下，首次进入时可使用轻提示说明当前限制（如“移动端已切换为时间轴视图”），用户理解后不再重复提示。
    

未在本节明确的降级行为不得自行实现，需先补充到本附录并通过评审后执行。

## 八、测试与兼容性要求

| 平台 | 最低版本 | 测试重点 |
|------|----------|----------|
| iOS Safari | iOS 14+ | 底部安全区（刘海）、WebSocket重连、Canvas性能 |
| Android Chrome | Chrome 90+ | 震动API、PWA安装、后台保活 |
| 微信内置浏览器 | 最新版 | 支付回调、文件上传（地图图片） |

**响应式断点**：
- 桌面端：`≥ 1024px`
- 平板：`768px - 1023px`（可使用桌面端布局，但触摸热区加大）
- 移动端：`< 768px`

### 8.1 验收指标

1. 跨端可见延迟 P95 小于 3 秒。
2. 自动保存成功率大于 99%。
3. 冲突发生率小于 2%。
4. 离线恢复成功率大于 99%。

## 九、总结

移动端适配不是简单地将桌面端缩小，而是**重新设计交互模型**以适应触摸、小屏幕和移动网络环境。本指南明确了：

- **保留核心跑团体验**（聊天、掷骰、角色卡）
- **高级功能降级但可用**（轨迹矩阵改为时间轴，网格地图改为坐标移动）
- **复杂编辑能力分层处理**（规则工坊 Recipe 编辑器引导至 PC 端；模组编辑器移动端开放基础文本编辑，复杂组件块只读）
- **性能与网络策略**确保流畅使用

前端开发应严格遵循本指南，并在必要时与产品确认交互细节。

### 九、社区评论系统移动端适配

#### 布局调整

- **主楼层**：卡片式布局，楼层号以圆形徽章（`border-radius: 50%`，直径 24px）显示在内容左上角，内容区正常展示。
- **楼中楼**：默认展示最近 3 条回复；超过 3 条时显示"共X条回复"展开按钮。展开后每条楼中楼左侧缩进 12px，并以浅色竖线（`border-left: 2px solid var(--color-border-light)`）标识层级关系。
- **回复操作**：点击"回复"按钮后，底部弹出输入框（固定在屏幕底部，`position: fixed; bottom: 0`），键盘弹起时输入框自动上移（监听 `visualViewport.resize`）。

#### 交互优化

| 操作 | 移动端行为 |
|------|----------|
| 楼层跳转 | 点击楼层号显示 Toast 提示"已复制链接"，不展开复杂菜单 |
| @提及 | 输入 `@` 后从底部弹出用户选择抽屉（`bottom-sheet`），支持搜索和滑动选择 |
| 加载更多 | 主楼层滚动到底部自动加载下一页，不显示"加载更多"按钮；楼中楼展开时一次性分页加载 |
| 发布回复 | 发布按钮固定在输入框右侧，轻触即可提交 |

#### 与桌面端的差异

| 功能 | 桌面端 | 移动端 |
|------|--------|--------|
| 输入框位置 | 页面底部内联 | 固定悬浮在屏幕底部 |
| @提及选择 | 下拉搜索框 | 底部滑出抽屉 |
| 楼层号点击 | 显示复制链接菜单 | 直接 Toast 提示 |
| 楼中楼折叠 | 默认展开最近3条 | 默认展开最近3条，超过部分折叠为计数入口 |
