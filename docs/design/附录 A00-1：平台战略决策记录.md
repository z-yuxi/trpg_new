# 附录 A00-1：平台战略决策记录

> **定位**：记录平台发展过程中已做出的关键战略决策及其理由。  
> **使用规则**：后续任何"要不要做 X"的讨论，必须先查阅本文。如果 X 已被明确否决，除非触发对应的重新评估条件，否则不再讨论。

---

## 决策 1：纯文字平台，不做视频资产

| 字段 | 内容 |
|------|------|
| **决策时间** | 项目启动时确定；2026-05-03 二次评估确认 |
| **状态** | ✅ 已锁定 |

### 决策内容

平台**不支持**视频上传、转码、播放。

仅支持：
- 静态图片：PNG / JPG / WebP
- 短动图：GIF / WebP 动图，≤3 秒，≤5 MB

### 理由

1. **产品定位**：共叙是以文字为载体的 TRPG 平台，视频不属于核心价值。
2. **成本悬崖**：视频存储和 CDN 成本是文字的 100 倍以上，且随用户增长线性放大。
3. **审核风险**：视频内容审核难度极大，MVP 团队无法承担。

### 重新评估条件

出现"用户强烈要求且付费意愿明确"的有效证据，**且**团队已具备专门的视频审核资源。

## 决策 2：纯 Web + PWA，不做原生应用

| 字段 | 内容 |
|------|------|
| **决策时间** | 项目启动时确定；2026-05-03 二次评估确认 |
| **状态** | ✅ 已锁定 |

### 决策内容

- **不做** Electron 桌面端
- **不做** iOS / Android 原生应用
- 仅通过 **PWA** 提供离线缓存和桌面安装能力

### 理由

1. 文字跑团不需要原生硬件能力（GPU、蓝牙、NFC 等）。
2. PWA 已覆盖离线、推送、桌面图标等核心体验。
3. 维护三套代码的成本远超收益。
4. Web 门槛更低，利于拉新（打开浏览器就能玩）。

### 重新评估条件

满足以下任意一项：
- 超过 30% 的活跃用户明确要求原生应用；
- PWA 存储限制（iOS 约 1 GB）已实质性阻碍文字数据存储；
- 需要接入应用商店原生支付渠道。

## 决策 3：AI 仅作为创作辅助工具，不做 AI 主持人

| 字段 | 内容 |
|------|------|
| **决策时间** | 项目启动时确定；已写入《产品设计》第 0 章 |
| **状态** | 🔒 永久锁定，不设重新评估条件 |

### 决策内容

AI 承担**校对、导入、摘要**等辅助工作。

AI **不参与**跑团房间内的实时叙事决策与规则判定。

### 理由

1. 平台核心价值在于人与人之间的**共同叙事**，AI 主持人会稀释这一价值。
2. 只要开一个口子，AI 就会从"辅助"滑向"替代"。
3. GM 的权威性来源于对规则判定的**最终决定权**，不能被 AI 架空。

### 重新评估条件

**永不重新评估。**

## 决策 4：规则引擎采用 Recipe 配方体系，废弃 L3 可视化画布

| 字段 | 内容 |
|------|------|
| **决策时间** | 2026-04-25 对齐；2026-05-03 确认清理 |
| **状态** | ✅ 已锁定 |

### 决策内容

- 规则定义使用 **Recipe 源码 + 编译产物**双层模型（详见附录 D03）。
- L3 可视化原子画布（`raw` 类型）**仅在 P1 阶段用于导入兼容封装**，不开放新建/编辑入口。

### 理由

1. 可视化画布维护成本高，用户学习门槛高。
2. Recipe 表单 + DSL 已覆盖 COC / DND / FATE 等主流系统的规则表达需求。

### 重新评估条件

用户强烈反馈 Recipe 表单无法满足某些规则表达时，再评估是否重新开放 `raw` 类型编辑入口。
