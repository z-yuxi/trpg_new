## 四、AI 代码生成时的强制约束

| 约束 | 文档来源 | 违规后果 |
|------|---------|---------|
| 禁止在新节点 attrs 里存完整实体属性 | 附录 E-1 §E-1.6 | 数据不一致，实体库失去权威性 |
| 禁止修改 ProseMirror/TipTap 内核 | 附录 E-1 §E-1.2 | 内核升级冲突，维护成本失控 |
| 禁止 KP/玩家切换修改原文档 | 附录 E-1 §E-1.5 | 意外触发保存操作，视图切换不可逆 |
| 禁止动旧块代码（SceneBlockExtension 等） | 附录 E-1 §E-1.2.1 | 回归测试安全网被破坏 |
| 禁止硬编码色值 | 附录 E-1 §E-1.4 | 日/夜间模式一致性破坏 |
| 禁止客户端未收到确认前清除草稿 | 附录 A00、附录 E-1-2 §E-1-2.1 | 用户数据丢失 |
| 禁止冲突时静默丢弃任何一方数据 | 附录 A00、附录 E-1-2 §E-1-2.3 | 用户内容永久丢失 |
