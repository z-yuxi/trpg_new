# 附录 00：状态行为映射表

> 状态：v1.0（权威口径）
> 用途：统一关键状态机，供产品、前后端与测试共同引用。

## 表 8：招募帖状态机

| 当前状态 | 允许转换到 | 触发条件 |
|---|---|---|
| draft | open | 发布招募帖 |
| open | full | 席位达到上限 |
| full | open | 席位释放或扩容 |
| open | grouped | GM 成团成功 |
| full | grouped | GM 成团成功 |
| open | closed | GM 手动关闭或截止时间到达 |
| full | closed | GM 手动关闭或截止时间到达 |
| grouped | dissolved | 流团/解散 |
| grouped | archived | 超时归档（策略触发） |
| closed | archived | 超时归档（策略触发） |

补充约束：
- grouped 后不可回退为 open 或 full。
- dissolved 与 archived 为终态，不可新增申请。

## 表 9：预约移动状态机

| 当前状态 | 允许转换到 | 触发条件 |
|---|---|---|
| pending | approved | GM 批准并填写预约到达时间 |
| pending | executed | GM 批准时未填时间（立即执行） |
| pending | cancelled | 玩家取消或 GM 拒绝 |
| approved | executed | 时间推进触发自动执行（到达 execute_at_story） |
| approved | cancelled | GM 手动取消或目标场景失效自动取消 |

补充约束：
- 自动调度仅处理 approved 且 execute_at_story 非空的记录。
- pending 到 executed 属于快捷路径，允许与主路径并存。

## 表 10：module_status 存储与文案映射

| 存储枚举 | UI 文案 |
|---|---|
| selected | 已选定模组 |
| pending | 待定，人齐后商议 |
| none | 无模组，即兴开团 |

补充约束：
- improvisation 仅作为前端文案语义，不作为数据库/API 枚举值。
