# 附录 C04：故事录产品状态机

> 关联文档：[附录 C：跑团房间交互设计](./附录%20C：跑团房间交互设计.md)、[附录 B01：发现标签设计](./附录%20B01：发现标签设计.md)、[附录 C05：故事录 API 合同](./附录%20C05：故事录%20API%20合同.md)

## 1. 目标与范围

本文定义故事录条目的唯一生命周期状态与转换规则，用于消除以下歧义：

1. 完团后导出生成内容，默认处于什么状态。
2. 作者编辑后何时可发布、何时可回退。
3. 公开、非公开、归档、违规标记的权限边界。

适用对象：产品、前端、后端、测试、运营审核。

## 2. 生命周期状态定义

| 状态 | 含义 | 可见性 | 可编辑 | 可分享 | 可评论 |
|---|---|---|---|---|---|
| `draft` | 从日志导出或手动创建后的草稿态 | 仅作者、管理员 | 是（全量字段） | 否 | 否 |
| `private` | 作者私有保存，不进入公共列表 | 仅作者、管理员 | 是（全量字段） | 否 | 否 |
| `published` | 公开发布，进入故事录公共列表 | 全平台可见 | 仅可编辑摘要类字段 | 是 | 是 |
| `unlisted` | 已发布但不进入公共列表，仅链接可访问 | 知道链接者可见 | 仅可编辑摘要类字段 | 是 | 是 |
| `archived` | 作者主动归档，下线展示 | 仅作者、管理员 | 否 | 否 | 否 |
| `flagged` | 平台审核标记（侵权/违规） | 仅作者、管理员 | 否 | 否 | 否 |

说明：

1. 摘要类字段包括 `title`、`summary`、封面、标签等不改动正文语义的元数据。
2. 全量字段包括 `content`（ILF/Markdown 正文）与关联关系（`campaign_id`、`module_id`）。

## 3. 状态转换规则（唯一权威）

| 当前状态 | 允许转换到 | 触发方 | 触发操作 | 说明 |
|---|---|---|---|---|
| `draft` | `private` | 作者/管理员 | 保存为私有 | 保留可编辑性 |
| `draft` | `published` | 作者/管理员 | 发布（公开） | 进入公共列表 |
| `draft` | `unlisted` | 作者/管理员 | 发布（仅链接） | 不进入公共列表 |
| `private` | `draft` | 作者/管理员 | 重新编辑正文 | 用于再次打磨正文 |
| `private` | `published` | 作者/管理员 | 发布（公开） | 转公开 |
| `private` | `unlisted` | 作者/管理员 | 发布（仅链接） | 转非公开发布 |
| `published` | `unlisted` | 作者/管理员 | 更改可见性 | 从公共列表下线 |
| `unlisted` | `published` | 作者/管理员 | 更改可见性 | 恢复公共展示 |
| `published` | `archived` | 作者/管理员 | 归档 | 下线，停止评论与分享 |
| `unlisted` | `archived` | 作者/管理员 | 归档 | 同上 |
| `private` | `flagged` | 管理员 | 审核标记 | 违规处理 |
| `published` | `flagged` | 管理员 | 审核标记 | 违规处理 |
| `unlisted` | `flagged` | 管理员 | 审核标记 | 违规处理 |
| `flagged` | `draft` | 管理员 | 解除标记并回退 | 作者可重新编辑并再次发布 |

禁止转换：

1. `archived -> published/unlisted/private/draft`（不可逆）。
2. `flagged -> published/unlisted/private`（必须先 `flagged -> draft`）。

## 4. 核心流程（产品闭环）

```text
跑团日志导出/手动创建
  -> 创建故事录草稿 (draft)
     -> 编辑标题/摘要/正文 (仍为 draft)
        -> 保存为私有 (private)
           -> 可回到 draft 继续改正文
           -> 可直接发布为 published/unlisted
        -> 发布为 published/unlisted
           -> 可分享（链接/海报）
           -> 可编辑摘要类字段
           -> 可归档 archived（不可逆）

任意阶段（private/published/unlisted）
  -> 管理员审核标记 flagged
     -> 申诉通过后管理员解除并回退到 draft
```

## 5. 权限矩阵

| 操作 | 作者 | 管理员 | 其他登录用户 | 游客 |
|---|:---:|:---:|:---:|:---:|
| 创建草稿 | ✅ | ✅ | ❌ | ❌ |
| 编辑正文（draft/private） | ✅ | ✅ | ❌ | ❌ |
| 编辑摘要（published/unlisted） | ✅ | ✅ | ❌ | ❌ |
| 发布/更改可见性 | ✅ | ✅ | ❌ | ❌ |
| 删除 | ✅（仅 draft/private） | ✅（全部） | ❌ | ❌ |
| 归档 | ✅ | ✅ | ❌ | ❌ |
| 标记违规/解除标记 | ❌ | ✅ | ❌ | ❌ |
| 查看详情 | ✅（全部） | ✅（全部） | ✅（published/unlisted） | ✅（published/unlisted） |
| 评论 | ✅（published/unlisted） | ✅（published/unlisted） | ✅（published/unlisted） | ❌ |

## 6. 与叙阅器集成约束

1. `published/unlisted` 必须进入统一叙阅器流程，不允许新增故事录专用阅读壳层。
2. 可见性与插件能力（分享、评论、导出按钮）由状态和权限共同决定。
3. `flagged/archived/private/draft` 在叙阅器路由访问时必须先做权限校验。

## 7. 验收标准（测试必测）

1. 状态机合法转换覆盖率 100%。
2. 非法转换均返回明确业务错误码。
3. `published/unlisted` 的“仅摘要可编辑”规则可被后端强制执行。
4. `archived` 不可恢复为公开态。
5. `flagged` 条目对普通用户不可见。
