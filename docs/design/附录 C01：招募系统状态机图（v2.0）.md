# 招募系统状态机图（v2.0）

## 招募帖状态机

```
                    ┌─────────────────────────────────────────────────────┐
                    │               招募帖 (recruitment_posts)             │
                    └─────────────────────────────────────────────────────┘

  POST /recruitment
        │
        ▼
  ┌──────────┐   POST /:id/publish    ┌──────────┐
  │  draft   │ ──────────────────────▶│   open   │
  └──────────┘  (帖主操作，无截止)    └──────────┘
                                           │
                              满员时自动升级│  player_count_joined ≥ player_count_max
                                           ▼
                                      ┌──────────┐
                                      │   full   │
                                      └──────────┘
                                           │
                          ┌────────────────┤
            open/full     │   POST /:id/close (帖主)
                          ▼
                     ┌──────────┐
                     │  closed  │◀── (过期自动关闭，未来扩展)
                     └──────────┘

  open/full → POST /:id/group (帖主)
        │
        ▼
  ┌──────────┐   POST /:id/dissolve  ┌────────────┐
  │ grouped  │ ─────────────────────▶│ dissolved  │
  └──────────┘  (帖主操作)           └────────────┘

  ┌──────────┐
  │ archived │ ← 系统定期归档 closed/dissolved 超30天的帖子（未来）
  └──────────┘

状态总结：
  draft → open → full ─┐
                        ├→ grouped → dissolved
  open/full → closed   ─┘
  closed/dissolved → archived（未来）
```

### 状态转换矩阵

| 当前状态   | 操作              | 执行者   | 目标状态   | 条件                         |
|-----------|------------------|---------|-----------|------------------------------|
| draft     | publish          | 帖主    | open      | —                            |
| open      | close            | 帖主    | closed    | —                            |
| full      | close            | 帖主    | closed    | —                            |
| open/full | group            | 帖主    | grouped   | ≥1 名 confirmed 玩家         |
| grouped   | dissolve         | 帖主    | dissolved | —                            |
| 任意      | archive（定时）  | 系统    | archived  | closed/dissolved 超过 30 天   |

## 申请状态机

```
                   ┌───────────────────────────────────────────────────────┐
                   │         申请 (recruitment_applications)               │
                   └───────────────────────────────────────────────────────┘

  POST /:id/apply
        │
        ▼
  ┌─────────┐   GM approve  ┌─────────┐   玩家确认  ┌───────────┐
  │ pending │ ─────────────▶│ invited │ ───────────▶│ confirmed │
  └─────────┘               └─────────┘             └───────────┘
       │                         │
       │                         │ invited_expires_at 过期（cron 每5分钟扫描）
       │                         ▼
       │                    ┌─────────┐
       │   GM reject        │ expired │（逻辑上回到 pending，实际标为 rejected）
       ▼                    └─────────┘
  ┌──────────┐
  │ rejected │
  └──────────┘

  POST /:id/apply?type=waiting
        │
        ▼
  ┌─────────┐   候补递补（未来：GM 手动/自动）   ┌─────────┐
  │ waiting │ ─────────────────────────────────▶│ pending │
  └─────────┘                                   └─────────┘
```

### 申请状态转换矩阵

| 当前状态  | 操作                    | 执行者   | 目标状态  | 条件                           |
|----------|------------------------|---------|----------|--------------------------------|
| —        | apply (normal)         | 玩家    | pending  | 帖子 open/full，未重复申请      |
| —        | apply (waiting)        | 玩家    | waiting  | 帖子 full，未重复申请           |
| pending  | review(approve)        | GM      | invited  | —                              |
| pending  | review(reject)         | GM      | rejected | 可附带 reject_reason           |
| invited  | confirm                | 玩家    | confirmed| 未超过 invited_expires_at      |
| invited  | [cron 过期]            | 系统    | rejected | 超过 invited_expires_at        |
| waiting  | [未来：递补]            | 系统/GM | pending  | 出现名额空缺                    |
