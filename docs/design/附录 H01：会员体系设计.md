## 2. 订阅身份定义

subscription_type 是用户订阅身份的唯一字段，统一取值如下：

| 字段值 | 中文名称 | 说明 |
| --- | --- | --- |
| free | 免费版 | 默认身份，无付费订阅 |
| pro | 专业版 | 面向核心玩家与 GM 的增强订阅 |
| creator | 创作者版 | 面向商业创作者的经营型订阅 |

约束：

1. subscription_type 只表达订阅身份，不直接等于权限角色。
2. 创作者访问后台的角色判定仍允许 user_type 包含 creator 或 admin，但其订阅权益以 subscription_type 为准。
3. 其他文档引用会员身份时，只能复用上述枚举，不得新增别名或平行层级。

## 3. 会员等级与定价

| 等级 | 价格 | 核心定位 | 适用人群 |
| --- | --- | --- | --- |
| 免费版 | 0 元 | 基础跑团、基础角色卡、基础导出 | 所有注册用户 |
| 专业版 | 29 元/月；249 元/年 | 进阶 GM 与重度玩家工具包 | 核心玩家、GM |
| 创作者版 | 49 元/月；399 元/年 | 创作者经营与变现套件 | 模组/规则创作者 |

说明：创作者版与专业版为并列定位，不是简单叠加包；创作者版包含专业版面向创作经营所需的全部高阶权益。

## 4. 会员权益矩阵

| 权益 | 免费版 | 专业版 | 创作者版 |
| --- | --- | --- | --- |
| 创建团数量 | <=3 | 无限 | 无限 |
| 日志导出格式 | TXT、Markdown | TXT、Markdown、PDF、HTML、JSON、CSV | 全部 + 批量导出 |
| 网格地图 | 否 | 是 | 是 |
| 轨迹矩阵 | 否 | 是 | 是 |
| 场景连通与自动移动调度 | 否 | 是 | 是 |
| 模组/规则包销售抽成 | 20% | 20% | 0% |
| 创作者数据分析 | 否 | 否 | 是 |
| AI 功能调用配额 | 0 | 有限配额 | 更高配额 |
| 优先客服 | 否 | 是 | 是 |
| 去广告 | 否 | 是 | 是 |

补充说明：

1. AI 各任务的具体次数与计费规则由附录 H04 维护，但会员层级归属由本文定义。
2. 角色卡 PDF 导出、批量导出、书籍样式导出等所有会员限制，均以本文为准。
3. 任何页面如果出现与本文不一致的权益文案，应修正文案，不得修正文中口径来贴合页面现状。

## 5. 开团级高级模块权限

适用于：轨迹矩阵、网格地图、场景连通与自动移动调度。

1. 以上能力属于开团时可选高级模块，仅 pro 与 creator 可启用。
2. 团创建后默认不可随意改动，以避免中途策略漂移。
3. 团已启用后，团成员可按房间角色权限使用对应能力。
4. 免费 GM 不可为新团启用会员高级模块。
5. 会员到期后，历史数据保留，能力降级为只读或不可新增，不做硬删除。

## 6. 订阅生命周期与降级规则

1. 新用户首次订阅专业版或创作者版可享 30 天试用，正式策略变更以公告为准。
2. 试用期需完成支付签约授权，可在到期前取消自动续费。
3. 取消后权益保留到当前周期结束，到期自动降级为免费版。
4. 降级不删除历史数据，但写操作、扩容操作、会员入口将按能力分层锁定。
5. 降级后若涉及市场经营收益、AI 配额、钱包权益等口径，分别回指附录 H02、附录 H03、附录 H04。
