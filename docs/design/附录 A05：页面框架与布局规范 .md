## 一、页面通用交互规范

以下规范适用于平台所有页面，不逐一重复描述。如有例外在该页面章节中特别说明。

### 1.1 返回按钮

- 所有二级及以上页面左上角统一放置返回按钮 `< 返回`，点击返回上一级（路由回退）
- 一级标签页（探索/招募/房间/讨论/团途）无返回按钮
- 首页（`/`）和登录页（`/login`）无返回按钮

### 1.2 搜索功能（MVP 简化版）

- 列表类页面提供搜索框，支持关键字模糊匹配
- 用户输入后点击搜索按钮或按回车触发搜索，实时筛选当前列表结果
- MVP 阶段不做：输入态自动补全、拼音搜索、高级筛选、搜索历史
- 允许结果态增强：在搜索结果区域展示 `suggested_tags`（推荐标签），用于一键追加筛选条件

### 1.3 分页与加载

- 列表数据超过 20 条时使用分页或滚动加载（取决于页面类型，在具体章节中说明）
- 加载状态显示骨架屏或 Spinner
- 空状态显示 SVG 占位图 + 引导文案

### 1.4 异常处理

- 网络错误：顶部 Toast "网络连接失败，请重试"
- 操作失败：显示具体错误原因（如"房间码不存在"）

## 二、页面框架规范（所有后台页面强制复用）

> **适用范围**：创作者后台、个人中心、「团途」标签下的个人馆藏页、GM 控制台等所有"后台型"页面。  
> **核心原则**：所有后台页面必须复用统一的 `PageLayout` 容器，禁止每个页面独立手写布局。

### 2.1 页面容器（PageLayout）

所有后台页面必须包裹在统一的 `PageLayout` 组件内。该组件提供以下固定插槽：

```
┌─────────────────────────────────────────────────────────────┐
│ PageLayout（max-width: 1280px，居中，padding: 24px）         │
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ Header（标题区）                                         │ │
│ │  左：标题 + 描述（可选）        右：主操作按钮组          │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ Stats（统计卡片区，可选）                                │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ FilterBar（筛选工具栏，可选）                            │ │
│ │  左：筛选标签/下拉          右：搜索框 + 排序             │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ Content（内容区）                                        │ │
│ │  列表 / 网格 / 表单 / 空状态                              │ │
│ └─────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

#### 容器规则

| 属性 | 值 | 说明 |
|------|-----|------|
| 最小高度 | `100vh - 64px`（减去顶部导航） | 保证无内容时也不塌陷 |
| 背景色 | `var(--surface-page)` | 跟随日间/夜间模式 |
| 全局内边距 | `24px`（桌面）/ `16px`（平板）/ `12px`（移动端） | 所有区域共享同一内边距 |
| 最大内容宽度 | `1280px` | 居中显示，超宽屏不无限拉伸 |
| 区域间距 | `24px`（桌面）/ `16px`（移动端） | Header → Stats → FilterBar → Content 之间统一间距 |

### 2.2 Header（标题区）

**强制规则**：
- 高度固定：`auto`（由内容撑开，但最小高度 `48px`）
- 布局：`display: flex; justify-content: space-between; align-items: center;`
- 左组：页面标题（`--text-primary`, `24px`, `font-weight: 600`）+ 描述文字（`--text-secondary`, `14px`, `margin-top: 4px`）
- 右组：主操作按钮组
  - **主操作按钮（品牌色）必须位于最右侧**
  - **次操作按钮位于主按钮左侧，间距 `12px`**
  - 按钮顺序从左到右：次操作 → 主操作
  - 禁止在标题下方、内容区内部、卡片内部放置"新建/上传"类主操作

**错误示例**：
```
❌ [主操作] [次操作]        ← 顺序颠倒
❌ 标题
    [主操作]               ← 按钮在标题下方
❌ 卡片内右上角 [新建]       ← 主操作藏在卡片里
```

**正确示例**：
```
✅ 创作者仪表盘                              [管理模组] [进入规则工坊]
   集中查看规则集、模组与最近编辑动作...
```

### 2.3 Stats（统计卡片区）

**使用场景**：仪表盘、我的作品等需要展示关键数据的页面。

**强制规则**：
- 必须使用统一的 `DashboardStats` 组件，禁止手写
- 卡片网格：`display: grid; grid-template-columns: repeat(4, 1fr); gap: 16px;`
- 平板（<1024px）：`repeat(2, 1fr)`
- 移动端（<640px）：固定 `repeat(2, 1fr)`
- 卡片内部结构统一：
  ```
  ┌─────────────────┐
  │ 标签（14px，--text-secondary）│
  │ 数值（32px，--text-primary，font-weight: 700）│
  │ 辅助说明（12px，--text-muted）│
  └─────────────────┘
  ```
- **对齐方式统一为左对齐**，禁止居中对齐
- 内边距统一：`20px`
- 圆角统一：`var(--radius-lg)`（8px）

### 2.4 FilterBar（筛选工具栏）

**强制规则**：
- 高度固定：`48px`（桌面）/ `auto`（移动端可换行）
- 布局：`display: flex; justify-content: space-between; align-items: center;`
- 左组：筛选标签（Tag/Tab 切换），间距 `8px`
- 右组：搜索框（最小宽度 `240px`）+ 排序下拉（如有）
- 与下方内容区间距：`16px`
- 筛选标签样式必须使用 `FilterTag` 组件，禁止手写样式

**位置规则**：
- 筛选栏必须位于统计卡片区下方（如有）或标题区下方（如无统计区）
- **禁止将筛选标签放在内容卡片内部作为"卡片头部"**

### 2.5 Content（内容区）

**强制规则**：
- 背景色：`transparent`（继承 PageLayout 的 `--surface-page`）
- 卡片网格：
  - 桌面（≥1280px）：按内容类型映射。
    - 素材预览类：`repeat(4, 1fr)`
    - 管理卡片类：`repeat(2, 1fr)`
    - 列表类：`repeat(1, 1fr)`
  - 平板（≥768px）：`repeat(2, 1fr)`
  - 移动端：`repeat(1, 1fr)`
- 卡片间距：`16px`（桌面）/ `12px`（移动端）
- 空状态：必须使用统一的 `EmptyState` 组件，居中显示，包含 SVG 占位图 + 标题 + 描述 + 操作按钮（可选）

### 2.6 栅格系统

后台页面统一使用 12 列栅格，但内容区实际采用简化版：

```css
.page-content {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 16px;
}

/* 常见布局模式 */
.layout-full     { grid-column: span 12; }   /* 全宽：列表、表单 */
.layout-main     { grid-column: span 8; }    /* 主内容：2/3 */
.layout-sidebar  { grid-column: span 4; }    /* 侧边栏：1/3 */
.layout-half     { grid-column: span 6; }    /* 双栏：1/2 */
```

**创作者后台统一使用 `layout-full`**（单栏最大宽度 1280px），不采用左右分栏，避免与左侧导航竞争。

### 2.7 表单排版模式

#### 决策树

```
容器宽度 ≥ 600px ?
  ├─ 是 → 使用【垂直标签模式】（标签在上，控件在下）
  │        适用于：设置页、创建房间表单、发布招募帖
  └─ 否 → 使用【水平标签模式】（标签在左，控件在右）
           适用于：窄边栏（<300px）、工具栏内联配置、导演模式侧边面板
```

#### 垂直标签模式（标准表单页）

```
标签（14px，--text-secondary，margin-bottom: 6px）
[输入框 / 下拉框 / 文本域]（高度 40px，padding 10px 14px）
辅助文字（12px，--text-muted，margin-top: 4px）
```

- 表单项间距：`20px`
- 标签字体：`--text-secondary`，`font-weight: 500`
- 输入框背景：`var(--surface-page)`（日间）/ `var(--surface-card)`（夜间）

#### 水平标签模式（窄边栏/工具栏）

```css
.form-row-compact {
  display: flex;
  align-items: center;
  gap: 8px;
  padding: 6px 0;
  min-height: 32px;  /* Dense 密度 */
}

.form-row-compact label {
  width: 60px;
  flex-shrink: 0;
  font-size: 12px;
  color: var(--text-secondary);
  text-align: right;
}

.form-row-compact select,
.form-row-compact input {
  flex: 1;
  min-width: 0;
  height: 28px;  /* Dense 密度 */
  padding: 0 8px;
  font-size: 12px;
}
```

**红线**：窄边栏（<300px）内**绝对禁止**使用垂直标签模式。如果配置项超过 3 个，必须改用折叠面板或移至宽页面。

### 2.8 控件密度分级

| 等级 | 名称 | 控件高度 | 间距 | 字体 | 使用场景 |
|------|------|----------|------|------|----------|
| Dense | 紧凑 | 28-32px | 8px | 12px | 边栏、工具栏、导演模式面板 |
| Normal | 标准 | 40px | 16px | 14px | 常规表单、筛选栏 |
| Comfortable | 舒适 | 48px | 24px | 16px | 设置页、低频操作 |

### 2.9 响应式断点

| 断点 | 宽度 | 布局调整 |
|------|------|----------|
| Desktop | ≥1280px | 完整布局，4列网格 |
| Laptop | ≥1024px | 3列网格，边栏可折叠 |
| Tablet | ≥768px | 2列网格，部分边栏隐藏 |
| Mobile | <768px | 单列，筛选栏换行，操作按钮下沉 |

## 三、叙阅器页壳层规范

> **适用范围**：模组、规则包、故事录等所有可阅览作品页面。
> **核心原则**：叙阅器页不复用后台型 `PageLayout`，统一使用沉浸式阅览壳层；不同品类仅通过插件扩展，不单独派生新页面框架。

### 3.1 页面结构

叙阅器页统一由以下区域组成：

1. 顶部悬浮栏：返回、作品标题、分享、更多操作。
2. 阅览主体区：正文渲染区域，宽度按阅读舒适度限制。
3. 右侧辅助区（桌面端可选）：目录、笔记、作品信息插件位。
4. 底部进度条：显示阅读进度与章节定位。
5. 下方扩展区：评价、评论、相关推荐等非沉浸内容。

### 3.2 布局规则

| 区域 | 规则 |
|------|------|
| 顶部悬浮栏 | 固定顶部，滚动时保持可见，高度 `56px` |
| 阅览主体区 | 最大宽度 `840px`，桌面端居中，移动端满宽减内边距 |
| 右侧辅助区 | 仅桌面端显示，宽度 `280px`；平板及以下折叠进抽屉 |
| 底部进度条 | 固定底部，显示当前章节与总体进度 |
| 下方扩展区 | 与正文分区显示，背景使用 `var(--surface-page)`，避免破坏沉浸阅读 |

### 3.3 交互约束

1. 默认隐藏非必要管理元素，聚焦正文。
2. 作者与管理员的额外操作入口收纳在顶部悬浮栏右侧“更多操作”中。
3. 试读用户进入时，未开放内容必须显示明确边界，不得以留白代替。
4. 评论、评价、相关推荐不得插入正文中部，只能位于正文结束后的扩展区。
5. 复制限制、水印、版权声明等保护能力由叙阅器内核统一处理，页面层不得重复实现一套独立逻辑。

### 3.4 响应式规则

1. 桌面端：正文区 + 右侧辅助区双栏。
2. 平板端：正文区单栏，目录与笔记收纳为顶部按钮触发的抽屉。
3. 移动端：仅保留正文区与底部进度条，所有插件入口折叠进顶部与底部操作面板。

### 3.5 与编辑器基线的交叉引用

叙阅器是模组、规则包、故事录等作品的统一阅览组件。其阅览体验应与编辑器的结构化块视觉规范保持一致：

- 编辑器中的结构化块（▼/◆/☆/▸/【】/[]）在叙阅器中以相同的色条 + 背景渲染
- KP/玩家分层在叙阅器中默认以“玩家视角”展示
- 叙阅器不提供编辑功能，但提供与编辑器相同的大纲导航（只读）

编辑器的完整交互基线见 [《附录 E-1：模组编辑器交互基线》](./附录%20E-1：模组编辑器交互基线.md)。
