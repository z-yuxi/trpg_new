## 2. 钱包与货币字段基线

```sql
ALTER TABLE users ADD COLUMN free_coins BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '免费积分（行为获取）';
ALTER TABLE users ADD COLUMN balance BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '平台余额（人民币充值，单位：分）';
ALTER TABLE users ADD COLUMN subscription_type ENUM('free', 'pro', 'creator') DEFAULT 'free';
```

字段说明：

1. free_coins 用于行为积分、活动积分等非现金来源积分。
2. balance 用于真实支付后的余额沉淀与退款处理，单位固定为分。
3. subscription_type 为订阅身份字段，语义以附录 H01 为准。

## 3. 运营参数与配置化

以下数值只作为运营参数，不改变代码结构：

1. 积分购买比例，例如 1 元 = X 积分。
2. 积分兑换会员比例，例如 X 积分 = 1 个月会员。
3. 用户积分获取上限。
4. 创作者分成比例。

```typescript
export const pointsConfig = {
  purchaseRate: 10,
  membershipExchange: 1000,
  maxExchangePerYear: 3,
  creatorCommission: {
    free: 0.8,
    pro: 0.8,
    creator: 1.0,
  },
};
```

## 4. 积分与余额闭环

### 4.1 积分获取规则

| 行为 | 积分变化 | 每日/每次限制 |
| --- | --- | --- |
| 每日登录 | +5 | 每天 1 次 |
| 完成一次跑团（参与） | +10 | 每团 1 次 |
| 完成一次跑团（GM） | +20 | 每团 1 次 |
| 发布模组（审核通过） | +50 | 一次性 |
| 发布规则模板（审核通过） | +50 | 一次性 |
| 模组/规则包被点赞 | +1 | 无上限 |
| 购买积分 | 1 元 = 10 积分 | 正式上线后开放 |

### 4.2 积分消耗规则

| 消耗项 | 所需积分 | 说明 |
| --- | --- | --- |
| 购买付费模组/规则包 | 按商品定价 | 与人民币订单共用商品口径 |
| 兑换专业版会员 | 1000 积分/月 | 限时活动或运营开关控制 |
| 兑换头像框/主题 | 50 / 200 积分 | 永久道具示例 |

### 4.3 流水与审计

1. 所有积分变动记录写入 coin_transactions 表。
2. 用户可在“我的钱包”查看积分与余额明细。
3. 运营后台可导出流水用于对账、申诉与审计。

## 5. 支付、订单与分账

### 5.1 支付方式

1. 公测期间不接入真实支付。
2. 正式上线后接入微信支付与支付宝企业商户接口。

### 5.2 资金流设计

1. 用户购买模组/规则包时，优先使用支付机构分账能力，降低“二清”风险。
2. 用户购买会员与积分时，资金进入平台对公账户。
3. 积分消费不再触发现金流，仅影响账本与分账结算。

### 5.3 创作者分成与提现

| 用户类型 | 平台抽成 | 创作者所得 |
| --- | --- | --- |
| 免费版创作者 | 20% | 80% |
| 专业版创作者 | 20% | 80% |
| 创作者版创作者 | 0% | 100% |

补充规则：

1. 最低提现金额为 100 元。
2. 平台不额外收提现手续费，支付渠道手续费由创作者承担。
3. 创作者提现需完成身份证与银行卡实名认证。
4. 平台按监管要求报送经营收入，并处理代扣代缴与发票协助。

## 6. 支付降级与失败处理

### 6.1 支付回调失败处理

| 场景 | 策略 | 用户提示 |
| --- | --- | --- |
| 回调接口业务失败 | 立即返回 5xx，由支付渠道重试 | 用户无感知 |
| 重试 5 次后仍失败 | 记录到 payment_retry_queue，后台每小时主动查单补单 | 若最终成功，站内信通知 |
| 主动查询也失败 | 进入人工对账流程 | 用户可提交“支付遇到问题”工单 |

工程约束：

1. 回调处理必须幂等，以 transaction_id 去重。
2. 对账扫描脚本必须使用分布式锁。
3. 若支付渠道持续异常，前台应关闭新支付入口并显示“服务暂时不可用”，不得继续创建可扣款订单。

## 7. 公测与正式上线边界

1. 公测期间，会员订阅、现金购买、创作者提现统一显示“公测暂未开放”。
2. 公测期间积分可正常获取，但仅用于兑换免费内容。
3. 公测作品正式上线后可转为付费，并按正式分成比例起算收益。
4. 正式上线前须完成公司主体、对公账户、商户号与分账系统准备。
