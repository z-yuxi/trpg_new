## C02.1 设计目标

本规范定义开放、结构化、可扩展的跑团日志中间格式（ILF），用于：

1. 跨平台交换跑团数据。
2. 保留场、角色、剧情时间等叙事语义。
3. 作为下游转换器（HTML/PDF/Markdown/Replay/AI）的统一输入。

## C02.2 顶层结构

```typescript
interface ILFDocument {
  version: '1.0.0';
  metadata: ILFMetadata;
  campaigns: ILFCampaign[];
}
```

```typescript
interface ILFMetadata {
  exporter: { name: string; version: string; url?: string };
  exported_at: string; // ISO 8601
  ruleset_id: string;
  ruleset_name: string;
  license?: string;
}
```

```typescript
interface ILFCampaign {
  id: string;
  name: string;
  gm: ILFCharacterRef;
  players: ILFCharacterRef[];
  npcs?: ILFNPC[];
  scenes: ILFScene[];
  timeline: ILFTimeline;
}
```

## C02.3 时间与事件模型

1. 时间字段同时保留 `story_time`（剧情时间）与 `real_time`（现实时间）。
2. 事件类型最小集合：`message`、`scene_transition`、`system_event`、`gm_note`。
3. 允许可选角色快照，用于关键时刻复盘与导出。

## C02.4 扩展机制

1. 允许 `x_*` 扩展字段。
2. 解析器必须忽略未知扩展字段，不得因扩展字段中断解析。
3. 主版本内保持向后兼容：新增字段可选、现有字段语义不变。

## C02.5 转换器约束

1. 采用单向转换：ILF -> 目标格式。
2. 支持按权限过滤（例如过滤 `gm_only` 内容）。
3. 转换失败必须返回可定位的结构化错误，不得静默吞错。
