
## 三、整体页面架构

### 底部导航（5个）

| 导航 | 页面定位 | 核心任务 | 主要模块 |
| --- | --- | --- | --- |
| **探索** | 内容发现与内容沉淀 | 浏览模组与规则、发现故事与公示信息 | 模组集、规则包、故事录、公示处 |
| **招募** | 房间参与连接器 | 找房间 / 开团招人的双向连接 | 找房间、开团招人 |

| **团途** | 跑团人生叙事主页 | 角色档案、创作管理、资产收藏、成就印记、同好关系 | 个人名片、角色档案、创作台、个人馆藏、成长履迹、羁绊名录、创作者入口 |

### 顶栏右侧常驻入口

**桌面端**：用户头像（圆形，24px），点击后卡片从头像正下方弹出（右上角对齐），轻微回弹动效 200ms。点击卡片以外区域或再次点击头像收起。

**移动端**：用户头像（圆形，24px），点击后卡片从屏幕右侧滑入，左侧半透明遮罩。点击遮罩层关闭。

**头像下拉卡片结构**：

```
┌─────────────────┐
│ [头像] 昵称      │  ← 不可点击，仅信息展示
│ @username       │
├─────────────────┤
│ 🔔 通知          │  → 未读红点徽标，跳转 /notifications
│ 💬 私信          │  → 未读红点徽标，跳转 /messages
│ ⚙️ 设置          │  → 跳转 /settings
├─────────────────┤
│ 🚪 退出登录      │  → 二次确认弹窗
└─────────────────┘
```

顶部身份区在 MVP 阶段为信息展示不可点击；后续可扩展为多身份切换入口。

## 四、各页面详细设计

### 4.1 首页（独立入口页）

**定位**：首页独立于底部导航，仅承载品牌表达与冷启动引导。

**可见性规则**：

1. 未登录用户访问根路径时显示首页。
2. 已登录用户访问根路径时，自动跳转到「探索」。

**首页按钮规则**：

1. 首页仅保留一个主按钮。
2. 文案固定为「进入叙事」。
3. 点击后跳转注册/登录页。

**首页结构**：

1. 品牌文案区：品牌主 Slogan（不再设置首页 Banner 模块）。
2. 主按钮区：仅一个「进入叙事」按钮。
3. 内容预览区：精选模组、热门故事。
4. 页脚区：备案号、联系我们、协议。

### 4.2 探索

探索为平台内容发现入口，统一承接：

1. 模组集。
2. 规则包。
3. 故事录。
4. 公示处。

详细交互与筛选定义见《附录 B01：发现标签设计》。

### 4.3 招募

招募固定为双 Tab：

1. 找房间（GM 招募帖列表）。
2. 开团招人（玩家求组帖列表）。

付费模组授权口径沿用《附录 B》5.1「付费模组授权提示」与《附录 H》5.2A「模组授权与共享规则」：玩家加入使用付费模组的房间后无需重复购买。

### 4.4 房间

房间作为用户参与中的跑团管理入口，固定为：

1. 进行中。
2. 待开始。
3. 已结束。

### 4.5 讨论

讨论承接社区讨论与分享能力，固定为三个子板块：

| 板块 | 引导文案 | 定位 |
|------|---------|------|
| **技巧交流** | 来这，教大家点什么 / 学点什么 | 可复用的干货、方法、技巧 |
| **跑团分享** | 来这，晒你和跑团相关的所有成果 | 原创内容、跑团经历、创作成品 |
| **同好闲谈** | 来这，和大家随便聊聊天 | 唠嗑、吐槽、找同好 |

每个板块顶部提供四个筛选标签：`[全部]` `[精华]` `[长篇]` `[短篇]`。精华由管理员手动标记，长篇/短篇按正文 1000 字自动区分。

### 4.6 团途

**定位**：用户的专属跑团人生叙事主页，聚焦跑团成长记录、内容创作与社交展示。

**功能模块**：

| 模块命名 | 核心功能 | 个人名片打通逻辑 |
|:---|:---|:---|
| **个人名片** | 头像、昵称、跑团身份标签（玩家/GM/创作者）、核心数据（跑团次数、带团次数）、个人签名 | 下方各模块内容，可自主勾选是否同步展示到名片 |
| **角色档案** | 所有创建的角色卡，按在用/归档/收藏分类陈列；单张角色卡完整档案：背景设定、技能、跑团履历 | 可设置「本命角色」，同步展示到名片头图 |
| **创作台** | 模组创作全流程管理（草稿/已发布/已下架）；规则包创作管理；讨论区发布内容统一管理 | 可设置「代表创作」，同步展示到名片 |
| **个人馆藏** | 已获取模组（按已玩/待玩分类）；规则包收藏；后续可拓展头像框、勋章等数字资产 | 可设置「馆藏精选」，同步展示到名片 |
| **成长履迹** | 全维度成就体系（玩家向/GM向/创作者向）；专属勋章；成长里程碑 | 可设置「核心履迹」，同步展示到名片 |
| **羁绊名录** | 跑团搭子自动归档；团本羁绊小组；关注/粉丝双向管理 | 可设置「核心搭子」，同步展示到名片 |

**辅助功能**：页面底部极简辅助栏，收纳创作者入口等杂项功能，仅自己可见，不对外展示。

**入口规则**：
- 作为底部导航的一级标签存在（命名为「团途」）。
- 创作者入口仅创作者可见，非创作者不显示。

### 4.6A 小名片与个人主页

#### 4.6A.1 小名片（Hover Card）

**触发方式**：

| 平台 | 触发 | 关闭 |
|------|------|------|
| 桌面端 | 鼠标悬停在头像/昵称/提及上 300ms | 鼠标移出小名片区域 200ms 后消失 |
| 移动端 | 点击头像 | 点击遮罩层或下滑关闭 |

**展示内容**：头像（48px）、昵称、身份标签（玩家/GM/创作者，用户可控制是否显示创作者标签）、核心数据（跑团次数、精华帖数，全部为 0 时不展示该行）。不展示成就勋章、本命角色、代表创作（留给个人主页）。

#### 4.6A.2 个人主页（公开 Profile）

**定位**：用户对外展示的完整跑团人生页面，访问路径 /u/{uid}。

**与团途页面的关系**：

| 页面 | 访问者 | 展示内容 |
|------|--------|---------|
| 团途页面 | 用户本人 | 所有模块的完整内容，包含私密功能 |
| 个人主页 | 他人访问 | 仅展示用户通过「编辑展示」勾选对外可见的模块内容 |

**编辑展示入口**：用户在团途页面点击「编辑展示」进入编辑面板，控制各模块的对外可见性和展示内容。

**对外可见控制**：

| 模块 | 默认对外可见 | 可选对外内容 |
|------|:---:|------|
| 个人名片 | ✅ 是 | 昵称、身份标签、核心数据始终可见；签名可选 |
| 角色档案 | ❌ 否 | 可设置「本命角色」对外展示 |
| 创作台 | ❌ 否 | 可设置「代表创作」对外展示 |
| 个人馆藏 | ❌ 否 | 可设置「馆藏精选」对外展示 |
| 成长履迹 | ❌ 否 | 可设置「核心履迹」对外展示 |
| 羁绊名录 | ❌ 否 | 可设置「核心搭子」对外展示 |

**默认签名**：新用户未填写签名时，对外展示「准备开启第一场叙事」。

**预览功能**：编辑面板底部提供「预览个人主页」按钮。桌面端新标签页打开 /u/{uid}?preview=true，顶部常驻浅蓝色横幅「正在预览你的个人主页，其他用户看到的内容以此为准」。移动端底部抽屉（90% 高度）内嵌预览。预览数据来自编辑面板当前状态，通过 sessionStorage 快照传递。

### 4.7 设置（独立页面）

**入口**：头像下拉卡片 → 设置（`/settings`），不占用底部导航。

**定位**：承载账号安全、偏好配置、隐私与数据管理等系统级功能。

---

#### 4.7.1 页面结构

设置页包含以下区块，按逻辑顺序排列：

1. 账号安全
2. 主题偏好
3. 内容偏好
4. 通知偏好
5. 隐私设置
6. 数据管理
7. 页脚合规信息

---

#### 4.7.2 各区块详细设计

##### 账号安全

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 手机号 | 展示 + 更换按钮 | 当前绑定手机号（脱敏展示，如 138\*\*\*\*8888） | 更换时需验证新手机号 |
| 密码 | 设置/修改按钮 | 未设置时显示「未设置」 | 留空表示仅验证码登录；修改需验证手机号 |

交互规则：
- 更换手机号：点击「更换」→ 输入新手机号 → 获取验证码 → 输入验证码 → 确认更换
- 设置/修改密码：点击「设置」→ 输入新密码（两次确认）→ 手机号验证码确认 → 保存

##### 主题偏好

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 界面主题 | 单选 | 跟随系统 | 浅色 / 深色 / 跟随系统 |
| 字体大小 | 单选 | 标准 | 小 / 标准 / 大 |

切换主题后即时生效，无需刷新页面。

##### 内容偏好

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 规则偏好 | 多选 | 无 | COC 7th / D&D 5E / Pathfinder / 其他 |
| 题材偏好 | 多选 | 无 | 恐怖 / 奇幻 / 科幻 / 悬疑 / 历史 / 轻松 |

用于优化「探索」页的推荐内容排序。

##### 通知偏好

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|:---:|------|
| 站内通知 | 开关 | 开 | 关闭后不再收到站内通知中心的消息 |
| 邮件通知 | 开关 | 关 | 开启后重要通知同步发送邮件 |
| Push 通知 | 开关 | 关 | 开启后通过浏览器推送通知 |

每条开关独立控制，互不影响。关闭站内通知后，通知中心仍可手动查看，只是不再主动推送红点提醒。

##### 隐私设置

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|:---:|------|
| 个人主页可见范围 | 单选 | 公开 | 公开 / 仅同好可见 / 仅自己可见 |
| 私信可达范围 | 单选 | 所有人 | 所有人 / 我关注的人 / 无人 |
| 参与社区数据统计 | 开关 | 开 | 关闭后不再被纳入平台公开统计 |
| 允许用于 AI 训练 | 开关 | **关** | 开启后，平台可将你的公开内容用于 AI 模型训练；关闭后不用于任何 AI 训练。该开关不影响 AI 功能的正常使用（如智能校对、AI 导入等），仅控制内容是否可用于模型训练 |

交互规则：
- 个人主页设为「仅自己可见」后，他人访问 `/u/{uid}` 时显示「该用户已隐藏个人主页」
- 私信设为「无人」后，其他用户无法给你发私信，你自己仍可主动发起私信
- AI 训练授权关闭后，AI 功能调用时提交给模型的内容仅用于当次任务处理，不会被保留用于训练

##### 数据管理

| 设置项 | 类型 | 说明 |
|--------|------|------|
| 导出我的数据 | 按钮 | 系统异步生成数据包，生成完成后站内通知发送下载链接。数据包包含：个人资料、角色卡、跑团记录、发布内容、资产列表 |
| 删除账号 | 按钮（危险色） | 点击后弹出二次确认弹窗，需输入密码/验证码确认。确认后进入 15 天冷静期，期间可登录撤销。冷静期结束后所有数据永久删除 |

##### 页脚合规信息

固定展示三个链接，小号灰色文字，居中排列：用户协议、隐私政策、备案号。

---

#### 4.7.3 布局规范

**桌面端**：
- 复用 PageLayout 容器
- 左侧设置导航（200px 宽），六个区块名称纵向排列，当前区块高亮（左侧 3px 品牌色指示条）
- 右侧内容区，最大宽度 720px
- 表单采用垂直标签模式（标签在上，控件在下）

**移动端**：
- 顶部横滑 Tab（六个区块名），当前区块高亮
- 内容区单栏垂直滚动
- 触摸目标 ≥ 44px
- 页脚合规信息居中排列

#### 4.7.4 保存机制

- 所有设置项采用即时保存（修改后自动保存，无需手动点击保存按钮）
- 保存成功后轻提示 Toast：「已保存」
- 保存失败时提示：「保存失败，请重试」

### 4.8 通知中心（/notifications）

**入口**：头像下拉卡片 → 通知（/notifications）。

#### 页面结构

```
┌─────────────────────────────────────────────────┐
│ 通知                                    [全部已读] │
├─────────────────────────────────────────────────┤
│ [全部] [跑团] [社区] [系统]                       │
├─────────────────────────────────────────────────┤
│ ┌───────────────────────────────────────────┐   │
│ │ ● 你的帖子「常暗之厢」已被选为精华帖         │   │
│ │   系统通知 · 2026-05-01 14:30              │   │
│ └───────────────────────────────────────────┘   │
│ ┌───────────────────────────────────────────┐   │
│ │   老周通过了你的入团申请                    │   │
│ │   招募通知 · 2026-05-01 10:15              │   │
│ └───────────────────────────────────────────┘   │
│ ...                                             │
└─────────────────────────────────────────────────┘
```

#### 筛选标签

| 标签 | 包含的通知类型（来自附录 I03） |
|------|------|
| 全部 | 所有通知 |
| 跑团 | `apply_approved`、`apply_rejected`、`waitlist_promoted`、`group_success`、`group_dissolved`、`move_approved`、`move_rejected`、`move_cancelled` |
| 社区 | `comment_floor`、`comment_reply`、`at_mention`、`post_featured`、`feature_rejected` |
| 系统 | `report_result`、`system_announcement`、`achievement_unlocked`、`badge_earned` |

#### 单条通知卡片结构

```
● / ○     标题文案（加粗/普通）           ← 蓝点 = 未读，无点 = 已读
          摘要文案（可选，≤ 一行，灰色）    ← 私信预览、回复片段等
          类型标签 · 相对时间               ← 如「招募通知 · 3小时前」
```

**特殊行为**：单条通知可左滑删除（移动端）/ 悬停出现删除按钮（桌面端）。

#### 已读/未读规则

| 操作 | 效果 |
|------|------|
| 点击某条通知 | 标记该条为已读 + 跳转关联内容 |
| 点击顶部「全部已读」 | 当前筛选视图下所有未读通知批量标记已读 |
| 切换筛选标签 | 不自动标记已读 |

**关联内容跳转对照**：

| 通知类型 | 点击跳转 |
|---------|---------|
| 招募相关（申请通过/拒绝、候补转正等） | 招募帖详情页 |
| 成团/解散 | 房间页 |
| 评论/回复/@提及 | 对应帖子的对应楼层 |
| 举报结果 | 举报详情页（后续版本） |
| 成就/勋章 | 团途 → 成长履迹 |
| 系统公告 | 公告详情页 |

#### 通知保留策略

- 保留最近 **90 天**的通知
- 超期通知系统自动清理
- 已读通知超过 **30 天**自动归档（不展示在默认列表，可通过「更早的通知」展开查看）

#### 空状态

| 场景 | 展示 |
|------|------|
| 所有通知为空 | SVG 占位图 + 「暂无通知」 |
| 某筛选标签下为空 | 「该分类下暂无通知」 |


**移动端**：默认展示会话列表，点击某会话后全屏切换到聊天区，顶部有返回按钮回到会话列表。

#### 会话列表规则

**排序**：按最后一条消息时间倒序（最新消息在顶部）。

**单个会话卡片**：
- 头像（36px 圆形）+ 昵称
- 最后一条消息摘要（≤ 一行，超出省略号）
- 相对时间（如「刚刚」「5分钟前」「昨天」「3天前」）
- 未读消息数（蓝色小圆点 + 数字，超过 99 显示「99+」）

**搜索**：顶部搜索框，支持按昵称搜索会话。

#### 聊天区规则

**消息展示**：
- 文字消息：标准聊天气泡，自己的消息靠右（品牌色浅底），对方消息靠左（灰色底）
- 图片消息：缩略图展示（最大 200px 宽），点击放大查看
- 时间戳：每 5 分钟以上的时间间隔自动插入时间分割线（如「── 5月1日 14:30 ──」），不逐条显示

**发送规则**：
- 文字：输入框 + 发送按钮，支持 Enter 发送
- 图片：输入框旁「+」按钮，选择图片后上传并发送
- 发送后即时展示（乐观更新），失败时标记红色感叹号，点击可重试

**引用回复**：长按某条消息（移动端）/ 右键（桌面端），选择「引用回复」，输入框上方出现被引用消息的缩略预览。

#### 私信权限

受设置页「私信可达范围」控制：

| 设置值 | 效果 |
|--------|------|
| 所有人 | 任何用户可发起私信 |
| 我关注的人 | 仅互相关注的用户可发起私信 |
| 无人 | 无人可发起私信，但不影响已有会话 |

#### 空状态

| 场景 | 展示 |
|------|------|
| 无任何会话 | SVG 占位图 + 「暂无私信」 + 「去社区发现有趣玩家」按钮 |
| 搜索无结果 | 「未找到相关会话」 |
