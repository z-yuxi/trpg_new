
## 三、整体页面架构

### 底部导航（5个）

| 导航 | 页面定位 | 核心任务 | 主要模块 |
| --- | --- | --- | --- |
| **探索** | 内容发现与内容沉淀 | 浏览模组与规则、发现故事与公示信息 | 模组集、规则包、故事录、公示处 |
| **招募** | 房间参与连接器 | 找房间 / 开团招人的双向连接 | 找房间、开团招人 |
| **房间** | 跑团入口与管理 | 查看并进入我的房间 | 进行中、待开始、已结束 |
| **讨论** | 跑团话题交流与内容分享 | 讨论玩法技巧、分享跑团成果、同好社交 | 技巧交流、跑团分享、同好闲谈 |
| **团途** | 跑团人生叙事主页 | 角色档案、创作管理、资产收藏、成就印记、同好关系 | 个人名片、角色档案、创作台、个人馆藏、成长履迹、羁绊名录、创作者入口 |

### 顶栏右侧常驻入口

**桌面端**：用户头像（圆形，24px），点击后卡片从头像正下方弹出（右上角对齐），轻微回弹动效 200ms。点击卡片以外区域或再次点击头像收起。

**移动端**：用户头像（圆形，24px），点击后卡片从屏幕右侧滑入，左侧半透明遮罩。点击遮罩层关闭。

**头像下拉卡片结构**：

```
┌─────────────────┐
│ [头像] 昵称      │  ← 不可点击，仅信息展示
│ @username       │
├─────────────────┤
│ 🔔 通知          │  → 未读红点徽标，跳转 /notifications
│ 💬 私信          │  → 未读红点徽标，跳转 /messages
│ ⚙️ 设置          │  → 跳转 /settings
├─────────────────┤
│ 🚪 退出登录      │  → 二次确认弹窗
└─────────────────┘
```

顶部身份区在 MVP 阶段为信息展示不可点击；后续可扩展为多身份切换入口。

## 四、各页面详细设计

### 4.1 首页（独立入口页）

**定位**：首页独立于底部导航，仅承载品牌表达与冷启动引导。

**可见性规则**：

1. 未登录用户访问根路径时显示首页。
2. 已登录用户访问根路径时，自动跳转到「探索」。

**首页按钮规则**：

1. 首页仅保留一个主按钮。
2. 文案固定为「进入叙事」。
3. 点击后跳转注册/登录页。

**首页结构**：

1. 品牌文案区：品牌主 Slogan（不再设置首页 Banner 模块）。
2. 主按钮区：仅一个「进入叙事」按钮。
3. 内容预览区：精选模组、热门故事。
4. 页脚区：备案号、联系我们、协议。

### 4.2 探索

探索为平台内容发现入口，统一承接：

1. 模组集。
2. 规则包。
3. 故事录。
4. 公示处。

详细交互与筛选定义见《附录 B01：发现标签设计》。

### 4.3 招募

招募固定为双 Tab：

1. 找房间（GM 招募帖列表）。
2. 开团招人（玩家求组帖列表）。

付费模组授权口径沿用《附录 B》5.1「付费模组授权提示」与《附录 H》5.2A「模组授权与共享规则」：玩家加入使用付费模组的房间后无需重复购买。

### 4.4 房间

房间作为用户参与中的跑团管理入口，固定为：

1. 进行中。
2. 待开始。
3. 已结束。

### 4.5 讨论

讨论承接社区讨论与分享能力，固定为三个子板块：

| 板块 | 引导文案 | 定位 |
|------|---------|------|
| **技巧交流** | 来这，教大家点什么 / 学点什么 | 可复用的干货、方法、技巧 |
| **跑团分享** | 来这，晒你和跑团相关的所有成果 | 原创内容、跑团经历、创作成品 |
| **同好闲谈** | 来这，和大家随便聊聊天 | 唠嗑、吐槽、找同好 |

每个板块顶部提供四个筛选标签：`[全部]` `[精华]` `[长篇]` `[短篇]`。精华由管理员手动标记，长篇/短篇按正文 1000 字自动区分。

### 4.6 团途

**定位**：用户的专属跑团人生叙事主页，聚焦跑团成长记录、内容创作与社交展示。

**功能模块**：

| 模块命名 | 核心功能 | 个人名片打通逻辑 |
|:---|:---|:---|
| **个人名片** | 头像、昵称、跑团身份标签（玩家/GM/创作者）、核心数据（跑团次数、带团次数）、个人签名 | 下方各模块内容，可自主勾选是否同步展示到名片 |
| **角色档案** | 所有创建的角色卡，按在用/归档/收藏分类陈列；单张角色卡完整档案：背景设定、技能、跑团履历 | 可设置「本命角色」，同步展示到名片头图 |
| **创作台** | 模组创作全流程管理（草稿/已发布/已下架）；规则包创作管理；讨论区发布内容统一管理 | 可设置「代表创作」，同步展示到名片 |
| **个人馆藏** | 已获取模组（按已玩/待玩分类）；规则包收藏；后续可拓展头像框、勋章等数字资产 | 可设置「馆藏精选」，同步展示到名片 |
| **成长履迹** | 全维度成就体系（玩家向/GM向/创作者向）；专属勋章；成长里程碑 | 可设置「核心履迹」，同步展示到名片 |
| **羁绊名录** | 跑团搭子自动归档；团本羁绊小组；关注/粉丝双向管理 | 可设置「核心搭子」，同步展示到名片 |

**辅助功能**：页面底部极简辅助栏，收纳创作者入口等杂项功能，仅自己可见，不对外展示。

**入口规则**：
- 作为底部导航的一级标签存在（命名为「团途」）。
- 创作者入口仅创作者可见，非创作者不显示。

### 4.6A 小名片与个人主页

#### 4.6A.1 小名片（Hover Card）

**触发方式**：

| 平台 | 触发 | 关闭 |
|------|------|------|
| 桌面端 | 鼠标悬停在头像/昵称/提及上 300ms | 鼠标移出小名片区域 200ms 后消失 |
| 移动端 | 点击头像 | 点击遮罩层或下滑关闭 |

**展示内容**：头像（48px）、昵称、身份标签（玩家/GM/创作者，用户可控制是否显示创作者标签）、核心数据（跑团次数、精华帖数，全部为 0 时不展示该行）。不展示成就勋章、本命角色、代表创作（留给个人主页）。

#### 4.6A.2 个人主页（公开 Profile）

**定位**：用户对外展示的完整跑团人生页面，访问路径 /u/{uid}。

**与团途页面的关系**：

| 页面 | 访问者 | 展示内容 |
|------|--------|---------|
| 团途页面 | 用户本人 | 所有模块的完整内容，包含私密功能 |
| 个人主页 | 他人访问 | 仅展示用户通过「编辑展示」勾选对外可见的模块内容 |

**编辑展示入口**：用户在团途页面点击「编辑展示」进入编辑面板，控制各模块的对外可见性和展示内容。

**对外可见控制**：

| 模块 | 默认对外可见 | 可选对外内容 |
|------|:---:|------|
| 个人名片 | ✅ 是 | 昵称、身份标签、核心数据始终可见；签名可选 |
| 角色档案 | ❌ 否 | 可设置「本命角色」对外展示 |
| 创作台 | ❌ 否 | 可设置「代表创作」对外展示 |
| 个人馆藏 | ❌ 否 | 可设置「馆藏精选」对外展示 |
| 成长履迹 | ❌ 否 | 可设置「核心履迹」对外展示 |
| 羁绊名录 | ❌ 否 | 可设置「核心搭子」对外展示 |

**默认签名**：新用户未填写签名时，对外展示「准备开启第一场叙事」。

**预览功能**：编辑面板底部提供「预览个人主页」按钮。桌面端新标签页打开 /u/{uid}?preview=true，顶部常驻浅蓝色横幅「正在预览你的个人主页，其他用户看到的内容以此为准」。移动端底部抽屉（90% 高度）内嵌预览。预览数据来自编辑面板当前状态，通过 sessionStorage 快照传递。

### 4.7 设置（独立页面）

**入口**：头像下拉卡片 → 设置（/settings），不占用底部导航。

**页面结构**：账号安全（手机号、密码）、主题偏好（浅色/深色/跟随系统）、内容偏好（规则偏好、题材偏好多选）、通知偏好（站内/邮件/Push 开关）、隐私设置（个人主页可见范围、私信可达范围）、数据管理（导出数据、删除账号 15 天冷静期）、页脚合规信息。

**布局**：复用 PageLayout。桌面端左侧导航（200px）+ 右侧内容区；移动端顶部横滑 Tab + 单栏。

### 4.8 通知中心（独立页面）

**入口**：头像下拉卡片 → 通知（/notifications）。

**页面结构**：顶部标题「通知」、筛选标签 [全部] [跑团] [社区] [系统]、通知列表按时间倒序（未读蓝点）、点击跳转关联内容、支持单条删除和下拉刷新。

### 4.9 私信列表（独立页面）

**入口**：头像下拉卡片 → 私信（/messages）。

**页面结构**：桌面端左侧会话列表（240px）+ 右侧聊天区；移动端默认会话列表，点击后全屏切换聊天区。支持文字、图片、引用回复与举报消息。

### 4.10 移动端创作台入口规则（2026-04-27 修缮）

> **历史方案（参考）**：曾讨论在底部导航新增"创作台"第 6 项。已废弃，底部导航固定 5 项。

- 移动端**不新增**底部导航项；创作台入口通过以下两条路径可达：
  1. **顶栏图标**：`MainLayout` 顶栏右侧（返回键右侧区域）当用户为创作者时显示 `icon-workshop` 图标，点击进入 `/creator`；
  2. **个人页首屏卡片**：`Personal.vue` 中在用户信息卡与 Stats 卡之间插入高优先级"创作台"入口卡片（带品牌色边框）。
- 两条路径均在用户信息加载中时不显示（骨架态），避免"先隐藏后闪现"。
- 触控目标尺寸≥ 44×44px，满足移动端规范。
