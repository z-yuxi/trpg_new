## B01.1 定位与边界

探索是平台内容发现入口，统一承接：

1. 模组集。
2. 规则包。
3. 故事坊。
4. 公示处。

本附录只定义探索标签内容，不承接招募流程、评论规则与治理处罚。

## B01.2 子 Tab 结构

| 子 Tab | 定位 | 内容类型 |
| --- | --- | --- |
| 模组集 | 获取可跑内容 | 模组卡片 |
| 规则包 | 获取规则能力 | 规则包卡片 |
| 故事坊 | 跑团体验分享 | 完团日志、战报 |
| 公示处 | 平台治理透明窗口 | 公示期作品、异议入口 |

## B01.3 故事坊

### B01.3.1 内容来源

| 来源 | 操作 |
| --- | --- |
| 跑团日志导出 | 在“我的剧本”导出完成后，勾选“分享到故事坊草稿”，系统创建草稿帖 |
| 手动发布 | 在故事坊点击“发布故事”并填写内容 |

说明：V1.0 不做高光片段裁剪发布，不做导出后自动公开。

### B01.3.2 帖子结构

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 故事标题 |
| 摘要 | 否 | 100 字以内 |
| 正文 | 是 | 富文本，支持 Markdown |
| 氛围/主题标签 | 否 | 1-2 个标签 |
| 关联模组 | 否 | 关联一个模组 |
| 关联房间 | 否 | 关联一个已结束房间 |

### B01.3.3 筛选栏

| 筛选项 | 类型 | 说明 |
| --- | --- | --- |
| 规则体系 | 多选 | 与招募共享规则包列表 |
| 氛围/主题 | 多选 | 恐怖、悬疑推理、奇幻冒险、科幻、历史、轻松搞笑、情感治愈 |
| 关联模组 | 搜索 + 下拉 | 按模组名筛选 |
| 排序 | 单选 | 最新发布、最多表态 |

### B01.3.4 页面布局

1. 列表页：`PageLayout` + `FilterBar` + 卡片网格（桌面 4 列，平板 2 列，移动 1 列）。
2. 卡片内容：封面图（默认占位）→ 标题 → 作者/发布时间 → 表态 Top3 → 关联模组标签。
3. 详情页：标题、作者、正文、评论区（两层结构）。

## B01.4 公示处

1. 展示处于公示期的模组/规则包。
2. 支持按公示截止时间排序。
3. 所有注册用户可提交异议。

## B01.5 与其他板块联动

| 板块 | 核心问题 | 联动关系 |
| --- | --- | --- |
| 探索-模组集/规则包 | 我想跑这个内容吗 | 可跳转招募查看“正在招募” |
| 探索-故事坊 | 这个内容跑起来怎么样 | 故事帖可关联模组与已结束房间 |
| 招募 | 谁愿意一起跑 | 招募帖可关联模组 |

## 一、底部导航（最终版）

```
探索          招募          房间          讨论          我的
├模组集      ├找团玩      ├进行中      ├经验交流      ├资料
├规则包      └当GM       ├待开始      ├跑团心得      ├角色卡
├故事坊                  └已结束      └闲聊          ├资产（已获取作品）
└公示处                                              ├通知/私信
                                                    ├设置
                                                    └创作者入口（仅创作者可见）
```

| 标签 | 内容 | 对标原文档 |
|:---|:---|:---|
| **探索** | 模组集、规则包、故事坊（战报/完团日志）、公示处（公示期作品） | 原资产库集市 + 原社区故事坊 + 原社区公示处 |
| **招募** | 找团玩（GM 招募帖列表）、当 GM（玩家求组帖列表） | 原社区招募场 |
| **房间** | 我的房间列表（进行中/待开始/已结束） | 原我的团 |
| **讨论** | 经验交流、跑团心得、闲聊 | 原社区讨论区 |
| **我的** | 个人资料、角色卡管理、已获取作品、通知/私信、设置、创作者入口 | 原个人 + 原资产库我的 + 原角色卡管理 |

## 二、首页（独立于底部导航）

**首页不属于五个标签之一**，是用户打开网页第一眼看到的独立入口页。

**谁看得到首页**：仅未登录用户。已登录用户输入网址后直接进入“探索”页，跳过首页。

**首页结构**：

text

```
┌─────────────────────────────────────────────┐
│                                             │
│          [大幅品牌插画/氛围图]                │
│                                             │
│       共叙，专注人与人之间的共同叙事           │
│                                             │
│          [ 进入叙事 ]                        │
│                                             │
├─────────────────────────────────────────────┤
│  精选模组            热门故事                │
│  ┌────┐ ┌────┐      ┌────┐ ┌────┐         │
│  │    │ │    │      │    │ │    │         │
│  └────┘ └────┘      └────┘ └────┘         │
│               │
├─────────────────────────────────────────────┤
│  © 2026 共叙  |  备案号  |  联系我们  |  协议  │
└─────────────────────────────────────────────┘
```

**按钮规则**：首页只有一个按钮，文案固定为“进入叙事”，点击跳转注册/登录页。不做动态切换（因为已登录用户不会看到首页）。
