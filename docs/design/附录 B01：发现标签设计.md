## B01.1 定位与边界

探索是平台内容发现入口，统一承接：

1. 模组集。
2. 规则包。
3. 故事录。
4. 公示处。

本附录只定义探索标签内容，不承接招募流程、评论规则与治理处罚。

### B01.1.1 首页入口对齐（与 A07 一致）

平台初期首页不设置内容预览区，首页仅承担品牌表达与冷启动引导。

当平台同时满足以下条件时，首页可增加内容预览区：

1. 已发布模组数量 ≥ 20。
2. 故事录中完成的故事帖 ≥ 30。
3. 公示处有活跃的公示内容。

启用后，内容预览区包含：

1. 精选模组（人工推荐 + 下载量排序结合）。
2. 热门故事（按表态数排序，优先展示精华帖）。

刷新频率：每周一次。

## B01.2 子 Tab 结构

| 子 Tab | 定位 | 内容类型 |
| --- | --- | --- |
| 模组集 | 获取可跑内容 | 模组卡片 |
| 规则包 | 获取规则能力 | 规则包卡片 |
| 故事录 | 跑团体验分享 | 完团日志、战报 |
| 公示处 | 平台治理透明窗口 | 公示期作品、异议入口 |

## B01.3 故事录

### B01.3.1 内容来源

| 来源 | 操作 |
| --- | --- |
| 跑团日志导出 | 在“我的剧本”导出完成后，勾选“分享到故事录草稿”，系统创建草稿帖 |
| 手动发布 | 在故事录点击“发布故事”并填写内容 |

说明：V1.0 不做高光片段裁剪发布，不做导出后自动公开。

### B01.3.2 帖子结构

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 故事标题 |
| 摘要 | 否 | 100 字以内 |
| 正文 | 是 | 富文本，支持 Markdown |
| 氛围/主题标签 | 否 | 1-2 个标签 |
| 关联模组 | 否 | 关联一个模组 |
| 关联房间 | 否 | 关联一个已结束房间 |

### B01.3.3 筛选栏

| 筛选项 | 类型 | 说明 |
| --- | --- | --- |
| 规则体系 | 多选 | 与招募共享规则包列表 |
| 氛围/主题 | 多选 | 恐怖、悬疑推理、奇幻冒险、科幻、历史、轻松搞笑、情感治愈 |
| 关联模组 | 搜索 + 下拉 | 按模组名筛选 |
| 排序 | 单选 | 最新发布、最多表态 |

### B01.3.4 页面布局

1. 列表页：`PageLayout` + `FilterBar` + 卡片网格（桌面 4 列，平板 2 列，移动 1 列）。
2. 卡片内容：封面图（默认占位）→ 标题 → 作者/发布时间 → 表态 Top3 → 关联模组标签。
3. 详情页统一使用「叙阅器」渲染，故事录作为叙阅器的故事录插件类型接入；评论区仍采用两层结构挂载在阅览内容下方。

## B01.4 公示处

1. 展示处于公示期的模组/规则包。
2. 支持按公示截止时间排序。
3. 所有注册用户可提交异议。

## B01.5 与其他板块联动

| 板块 | 核心问题 | 联动关系 |
| --- | --- | --- |
| 探索-模组集/规则包 | 我想跑这个内容吗 | 可跳转招募查看“正在招募” |
| 探索-故事录 | 这个内容跑起来怎么样 | 故事帖可关联模组与已结束房间 |
| 招募 | 谁愿意一起跑 | 招募帖可关联模组 |

## B01.7 模组详情页内容聚合

### 一、聚合内容类型

在模组信息页（模组集市中的详情展示页面）底部，增加“社区讨论”板块，聚合展示三类内容：

| 内容类型 | 数据结构 | 呈现方式 |
| --- | --- | --- |
| 模组评价 | 文字 + 表情表态 + 点赞数 + module_id | 评价卡片，按时间或热度排序 |
| 高光时刻分享 | 分享卡片 + 选中消息摘要 + 发布者信息 + module_id | 分享卡片，显示“来自《模组名》的精彩片段” |
| 讨论区相关帖子 | 引用该模组的讨论帖 + module_id | 帖子卡片，显示标题、作者、回复数 |

### 二、标签筛选

在“社区讨论”板块顶部，统一使用标签筛选组件：

	[全部] [评价] [精彩片段] [讨论帖]

| 标签 | 展示内容 |
| --- | --- |
| 全部 | 按时间倒序混合展示所有内容卡片 |
| 评价 | 仅展示模组评价卡片 |
| 精彩片段 | 仅展示高光时刻分享卡片 |
| 讨论帖 | 仅展示引用该模组的讨论帖 |

交互规范：默认展示“全部”，用户点击标签后切换，标签样式和交互行为与讨论区筛选标签一致。

### 三、模组评价的卡片展示

延续之前的评价体系设计（见《附录 B：平台帖子与招募规范》），不使用星级评分。评价卡片包含：

| 展示元素 | 说明 |
| --- | --- |
| 评价者信息 | 头像、昵称、评价时间 |
| 评价正文 | 文字评价 |
| 表情表态 | 评价者发表时可附带表情，从平台预设的6种表情中选择 |
| 点赞数 | 其他用户可给评价点赞 |
| 置顶标识 | 创作者可置顶一条优质长评，置顶评价有特殊标识 |

### 四、统一筛选标签规范

全平台各页面的筛选标签，统一使用同一套组件：

| 页面 | 筛选标签 |
| --- | --- |
| 讨论区（技巧交流） | [全部] [精华] [长篇] [短篇] |
| 讨论区（跑团分享） | [全部] [精华] [长篇] [短篇] |
| 模组详情页（社区讨论） | [全部] [评价] [精彩片段] [讨论帖] |

标签的位置、样式、交互行为，三处保持一致。

### 五、技术实现要点

1. 高光时刻分享的数据结构与跑团日志导出功能在底层完全兼容，均基于chat_messages表中一组消息的组合展示。
2. 模组详情页的三类内容（评价、分享、讨论帖）共用同一套卡片渲染组件和标签筛选组件。
3. 分享卡片生成不需要AI参与，是纯前端交互+后端数据打包。
