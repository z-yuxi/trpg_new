## I03.1 通知渠道

| 渠道标识 | 说明 | 技术实现 |
| --- | --- | --- |
| `in_app` | 站内通知中心 | 数据库 `notifications` 表 |
| `socket` | 在线实时推送 | Socket.IO `/user` 命名空间 |
| `push` | 离线 Push 通知（可选） | PWA Service Worker |
| `email` | 邮件通知（可选） | 用户可在设置中关闭 |

## I03.3 去重规则

1. 同类事件在去重窗口内多次触发时，仅保留最新一条，更新通知内容和时间戳。
2. 成团、移动审批等高优先级通知（`priority = high`）不参与合并。
3. 去重窗口在配置中定义，可按事件类型覆盖。

---

## I03.4 持久化与清理

1. 通知内容存储于 `notifications` 表，实时推送不持久化（仅通过 Socket 发送）。
2. 已持久化通知保留 90 天，超期自动删除。

## I03.5 举报与申诉通知文案模板

### I03.5.1 `report_result` 事件文案

**接收人：举报人**

| 处置结果 | 通知标题 | 通知正文 |
| --- | --- | --- |
| 举报成立（内容被处理） | 举报处理结果 | 你举报的{内容类型}已被处理。处理结果：{处置方式}。感谢你对社区秩序的维护。 |
| 举报被驳回 | 举报处理结果 | 你举报的{内容类型}经审核未发现违规。如有疑问，可补充证据后重新提交。 |

**接收人：被举报人**

| 处置结果 | 通知标题 | 通知正文 |
| --- | --- | --- |
| 内容被删除/下架 | 内容违规处理通知 | 你的{内容类型}因违反社区规范已被处理。处理原因：{处置说明}。如有异议，可在 7 天内提交申诉。 |
| 账号被限制/封禁 | 账号限制通知 | 你的账号因违反社区规范已被{处置方式}。处理原因：{处置说明}。如有异议，可在 7 天内提交申诉。 |

### I03.5.2 `appeal_result` 事件文案

**接收人：申诉人**

| 处理结果 | 通知标题 | 通知正文 |
| --- | --- | --- |
| 维持原处罚 | 申诉处理结果 | 你的申诉经复核后，维持原处罚决定。 |
| 撤销处罚 | 申诉处理结果 | 你的申诉经复核后，原处罚已撤销，相关内容已恢复。 |

**变量说明**

| 变量 | 来源 |
| --- | --- |
| `{内容类型}` | 帖子 / 评论 / 私信 / 模组 / 用户主页 |
| `{处置方式}` | 删除内容 / 下架作品 / 限制发帖评论 N 天 / 永久封禁 |
| `{处置说明}` | 管理员在处理面板填写的处置说明文本 |
