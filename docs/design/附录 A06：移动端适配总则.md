
## 一、整体布局适配

| 元素 | 桌面端 | 移动端 |
|------|--------|--------|
| **底部导航** | 5个文字+图标（高度48px） | 5个图标+隐藏文字（长按显示标签），高度56px，触摸热区≥44px |
| **页面内边距** | 24px | 16px |
| **卡片/网格** | 多列响应式（4列→2列） | 默认2列，列表项高度≥56px |
| **筛选栏** | 多行横向排列 | 顶部显示2-3个主要筛选项，其余折叠入“更多筛选”底部抽屉 |
| **模态框** | 居中弹窗（宽≤500px） | 全屏底部抽屉（可从下滑关闭），圆角顶部16px |

#### 1.1.1 主操作按钮放置规则（移动端）

为避免长标题挤压按钮，主操作按钮采用双模式：

| 场景 | 按钮位置 | 示例 |
|---|---|---|
| 标题短（<=4 字）且单一主操作 | Header 右上角 | 素材库 + 上传素材 |
| 标题长、说明文本存在或需要双按钮 | 使用浮动 FAB | 创作者仪表盘 + 管理模组/进入规则工坊 |

**FAB 规范（采用 FAB 时必须遵守）**：
- 位置：`right: 16px; bottom: 72px`（避开全局底部导航）。
- 尺寸：`56px x 56px`，圆形。
- 色值：`background: var(--color-primary)`，图标白色。
- 交互：点击展开动作菜单（新建模组/新建规则集/上传素材）。

#### 1.1.2 FilterBar 结构与二级筛选规范

移动端 FilterBar 统一结构：固定显示 2-3 个高频项 + 更多筛选入口 + 搜索入口。

```plain
[全部] [草稿] [已发布] [更多筛选 ▼] [🔍]
```

点击“更多筛选”后，底部抽屉必须包含：
1. 状态筛选。
2. 规则包筛选（如页面适用）。
3. 排序方式。
4. 操作区（重置 / 应用筛选）。

各页面高频筛选项统一如下：

| 页面 | 固定显示 | 抽屉内 |
|---|---|---|
| 仪表盘 | 无 FilterBar | 无 |
| 素材库 | 全部 / 图片 / 音频 | 排序（上传时间 / 名称 / 大小） |
| 我的作品 | 全部 / 草稿 / 已发布 | 审核中 / 已弃用 + 规则包筛选 + 排序 |
| 规则工坊 | 全部 / 我的 / 已发布 | 规则包类型 + 排序 |

## 二、手势与触摸规范

| 手势 | 用途 | 适用场景 |
|------|------|----------|
| **点击** | 选中、打开、提交 | 所有按钮、卡片、列表项 |
| **长按（>=500ms）** | 打开上下文菜单 | 房间卡片（管理）、消息（举报）、时间轴节点（GM操作） |
| **左滑** | 删除/归档 | 通知列表、私信会话 |
| **右滑** | 返回上一页 | 全屏抽屉、详情页 |
| **双指缩放** | 放大查看 | 地图、图片、复杂图表（如轨迹矩阵时间轴） |
| **下拉刷新** | 刷新列表 | 招募板、动态、消息列表 |

注意：避免与系统手势冲突（如 iOS 左滑返回），边缘区域需保留系统手势。

## 三、性能与体验优化

| 优化项 | 策略 |
|--------|------|
| **懒加载** | 聊天消息按需加载（每次 20 条），滚动顶部加载更多；轨迹矩阵时间轴虚拟滚动 |
| **网络不稳定** | WebSocket 自动重连，断线时显示顶部横幅“连接中...”，重连后拉取缺失消息（通过 `missed_messages` 事件） |
| **后台保活** | PWA 使用 Service Worker 缓存静态资源；跑团房间心跳保持（每 30 秒 ping），移动端允许后台断开，重连后同步 |
| **资源压缩** | 地图图片自动压缩为 WebP，头像使用 CDN 且尺寸自适应（`?x-oss-process=image/resize,w_200`） |
| **触感反馈** | 关键操作（发送消息、掷骰、创建房间）使用轻震动（仅 Android，需用户授权） |

## 四、移动端功能降级原则

| 功能类型 | 降级方式 | 基本要求 |
|---|---|---|
| **规则工坊 Recipe 编辑器** | 只读查看 | 保留查看入口，所有编辑控件统一隐藏，提示请在电脑上使用此功能 |
| **模组编辑器（富文本+Mention）** | 轻量可编辑 | 开放元信息、纯文本段落、标题层级编辑；Mention 对应复杂实体只读；图片/音频仅查看 |
| **可视化日志编辑器** | 完全禁用 | 移动端不提供入口；通过其他入口访问时统一提示请在电脑上使用此功能 |
| **空间操作工具**（网格地图、轨迹矩阵） | 简化交互 | 将拖拽/画布操作改为表单/列表选择；核心数据可查看并通过受控入口修改 |
| **场景连通配置** | 只读查看 | 移动端仅查看路径列表，编辑入口统一引导至 PC |
| **数据可视化图表**（创作者后台统计图） | 降级为表格 | 用纯数字表格替代图形化图表 |

通用要求：

1. 禁用功能点击时，使用 Toast 引导到 PC，文案统一为“请在电脑上使用此功能”。
2. 只读视图需保留核心信息展示，不得因降级导致数据丢失或不可见。
3. 简化交互模式下，首次进入可轻提示说明当前限制（如“移动端已切换为时间轴视图”），用户理解后不再重复提示。

## 五、测试与兼容性要求

| 平台 | 最低版本 | 测试重点 |
|------|----------|----------|
| iOS Safari | iOS 14+ | 底部安全区（刘海）、WebSocket 重连、Canvas 性能 |
| Android Chrome | Chrome 90+ | 震动 API、PWA 安装、后台保活 |
| 微信内置浏览器 | 最新版 | 支付回调、文件上传（地图图片） |

响应式断点：

1. 桌面端：`>= 1024px`
2. 平板：`768px - 1023px`（可使用桌面端布局，但触摸热区加大）
3. 移动端：`< 768px`

验收指标：

1. 跨端可见延迟 P95 小于 3 秒。
2. 自动保存成功率大于 99%。
3. 冲突发生率小于 2%。
4. 离线恢复成功率大于 99%。
