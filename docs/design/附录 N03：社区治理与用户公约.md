## N03.1 职责边界

本附录负责：

1. 社区信誉分、排序权重、发帖限制与恢复机制。
2. 自动化举报初筛、处罚等级、申诉与管理员执纪规则。
3. 平台完整用户公约与社区行为边界。

本附录不负责：

1. 社区信息流、招募流程与评论交互本体。
2. 法律合规、隐私政策、侵权投诉与版权存证。
3. 掷骰可信、引擎沙箱与技术执行安全。

## N03.2 信誉分体系

### N03.2.1 设计目标

通过量化用户行为，自动影响招募排序权重、举报处置等级、发帖频控阈值，抑制恶意用户，激励正面行为。

### N03.2.2 分值构成

初始分 100，范围 0-120。

| 行为类型 | 分值变化 | 触发条件 |
| --- | --- | --- |
| 完成一次跑团且双方互评 | +2 | 跑团结束 7 天内双方完成评价 |
| 获得对方好评（4 星及以上） | +1 | 每次评价 |
| 发布招募帖并成功成团 | +3 | 成团瞬间 |
| 高光被点赞 > 10 | +1 | 每 10 赞，上限 +5/帖 |
| 举报被核实有效 | +1 | 每日上限 +5 |
| 申请后未确认超时 | -2 | 每次 |
| 成团后无故退出 | -5 | 需 GM 提交原因，用户可申诉 |
| 被删除违规评论 | -3 至 -10 | 视违规等级 |
| 被禁言 | -15 | 每次处罚 |
| 流团且 GM 无合理解释 | -10 | GM 主动解散 |
| 虚假原创性声明 | -15 至 -30 | 经举报或审核核实，夸大原创比例、声称持有授权但无法举证 |

### N03.2.3 等级与影响

| 信誉分 | 等级 | 影响 |
| --- | --- | --- |
| >= 110 | 极佳 | 发帖频控提升 2 倍，招募排序加权，可申请优秀 GM 标识 |
| 90-109 | 良好 | 默认权益 |
| 70-89 | 一般 | 发帖需验证码，招募排序降权 20% |
| 50-69 | 较差 | 每日仅能发 1 帖，评论需审核 |
| < 50 | 差 | 禁止发帖，评论仅自己可见，可申诉恢复 |

### N03.2.4 恢复机制

1. 每完成一次无违规跑团恢复 1 分，每周上限 5 分。
2. 连续 30 天无负面行为自动增加 2 分，上限回归到 100。
3. 运营活动可额外加分，但不得越过 120 上限。

## N03.3 举报初筛与处罚等级

### 自动分流

| 举报类型 | 机器初筛逻辑 | 动作 |
| --- | --- | --- |
| 违法/色情 | 关键词库 + OCR/哈希比对 | 自动进入 L4，等待人工复核 |
| 刷屏/广告 | 短时间重复相似内容 | 自动删除 + L1 警告 + 信誉分 -5 |
| 人身攻击 | 攻击性关键词 + 多次举报 | 进入 L2 待人工复核，临时折叠 |
| 骚扰私信 | 频率异常 + 举报数量 | 自动限制私信权限 7 天 |

### 处罚等级

| 等级 | 自动处置 | 人工复核时限 |
| --- | --- | --- |
| L1 轻微 | 删除内容 + 警告 + 信誉分 -2 | 24 小时内无异议生效 |
| L2 中度 | 限制发帖/评论 1 天 + 信誉分 -10 | 12 小时内确认 |
| L3 严重 | 下架内容 + 限制发帖 7 天 + 信誉分 -30 | 4 小时内必须复核 |
| L4 极严重 | 临时冻结账号，等待终审 | 24 小时内出结果 |

补充规则：

1. 用户信誉分 < 60 时自动触发隐形降权，自己可见、他人默认折叠。
2. 所有自动处置用户可立即发起申诉。
3. 管理员手动处罚必须填写原因、证据与执行人。

## N03.4 管理员执纪细则

1. 所有举报只接受平台内置通道，不接受口头或群聊截图作为唯一依据。
2. 处罚默认采用双人复核：一人初判，一人复核，意见不一致时提交负责人裁定。
3. 处理通知必须通过系统消息发送，写明违规行为、对应条款、处罚措施与申诉入口。
4. 公示违规案例时必须隐去真实姓名、头像、联系方式等个人隐私。
5. 管理员不得因个人偏好随意处罚、泄露隐私、谋取不正当利益或打击报复。

## N03.5 共叙社区用户公约

### 前言

我们相信，叙事的核心永远是人。平台以“人与人之间的共同叙事”为初心，搭建包容、原创、有温度的垂直创意演绎生态。本公约旨在明确社区共识、划定行为边界，守护每一位用户安心创作、自在交流的空间。

### 第一章 核心原则

1. 平等与尊重：任何用户都不因身份、经验、规则偏好、演绎风格、创作水平等差异受到歧视、贬低或差别对待。
2. 人本与共创：平台规则与功能以服务叙事和联结用户为核心，拒绝工具内卷和排他式优越感。
3. 原创与合规：尊重知识产权，遵守法律法规，不发布、传播违规、侵权、低俗或违背公序良俗的内容。

### 第二章 分场景行为规范

#### 创作者与模组专区

1. 禁止抄袭、洗稿、恶意爬取和未授权搬运他人原创内容。
2. 引用他人内容需明确标注来源，不得侵犯著作权、商标权等合法权益。
3. 不得以“规则正统”“风格高低”等理由贬低他人作品。4. **禁止滥用创作者身份**：创作者不得以"我是某模组的作者"为由，在其他 GM 的房间内干涉其主持决策、压迫其他玩家、或要求特殊待遇。创作者在他人主持的房间中，仅享有与普通玩家同等的游戏权利。
5. **公平评价与讨论**：创作者不得因他人对自己的作品提出批评或不同意见，而对批评者进行人身攻击、恶意举报或组织他人围攻。
#### 玩家与主持人对局

1. 玩家与 GM 均应尊重彼此的叙事边界、角色选择与合理诉求。
2. 禁止剧透、恶意搅局、角色 OOC 攻击、歧视性言论和破坏体验行为。
3. 未经同意，不得录制、传播对局内容或追问他人隐私信息。

#### 论坛与交流社区

1. 禁止人身攻击、引战、KY、阴阳怪气、刷屏与广告骚扰。
2. 讨论应就事论事，不上升到对用户本人的攻击。
3. 不得恶意举报、造谣、传播未经证实的信息。

### 第三章 违规处理与申诉

1. 平台根据违规等级采取警告、限权、下架、冻结、封禁等措施。
2. 用户收到处罚通知后，可在 7 个工作日内提交申诉并提供证据。
3. 平台在 3 个工作日内完成复核，复核结果为最终处理决定。
4. **滥用创作者身份**：在游戏内以创作者身份压迫其他玩家的行为，属于"中度违规"（L2）。经核实后，对创作者进行信誉分从重处罚（扣分幅度为普通违规的 1.5 倍），因其行为损害了整个创作者群体的声誉。

### 第四章 用户权利与义务

1. 用户有权在遵守公约前提下进行创作、交流、演绎、讨论与举报。
2. 用户有义务遵守法律法规、平台规则、尊重他人权益并配合合理治理。
3. 管理员必须公平、公正、可审计地行使管理权限。
4. **禁止虚假声明**：禁止在模组发布流程中作出虚假的原创性声明或授权声明，包括但不限于：虚报原创比例、伪造授权证明、隐瞒 IP 使用情况。违反者除模组下架外，将按信誉分规则扣除 15–30 分，情节严重者可撤销创作者资格。

### 第五章 修订与附则

1. 平台可根据法律法规、社区发展与用户反馈修订本公约。
2. 修订后的公约通过平台公告公示，公示期 7 天后生效。
3. 未尽事项，平台按法律法规、公序良俗与本公约核心原则处理。

## N03.6 举报提交交互

### N03.6.1 举报入口

全平台所有可被举报的内容类型统一在操作栏提供「举报」按钮：

| 内容类型 | 入口位置 | 图标 |
| --- | --- | --- |
| 帖子（招募帖/讨论帖/故事帖） | 帖子操作栏 | `SvgIcon: icon-report` |
| 评论（主楼层/楼中楼） | 评论右侧操作区 | 同上 |
| 私信消息 | 长按/右键菜单 | 文案「举报」 |
| 模组/规则包 | 详情页操作栏 | 同上 |
| 用户主页 | 主页右上角 | 同上 |

### N03.6.2 举报表单字段规则

| 字段 | 必填 | 说明 |
| --- | :---: | --- |
| 举报类型 | 是 | 下拉选择：违规内容 / 侵权内容 / 社区秩序 / 交易风险 / 其他 |
| 详细说明 | 否 | 200 字以内 |
| 证据截图 | 否 | 最多 3 张，每张 ≤ 5 MB |

**提交后反馈**：
- 即时 Toast：「举报已提交，平台将在 3 个工作日内处理」
- 同一用户对同一内容重复提交时，Toast：「你已举报过此内容，请等待处理结果」

### N03.6.3 举报频控

| 限制项 | 值 |
| --- | --- |
| 每用户每日举报上限 | 10 次 |
| 同一用户对同一内容 | 仅可举报 1 次 |

## N03.7 管理员审核后台

### N03.7.1 举报处理列表

| 列 | 内容 |
| --- | --- |
| 举报时间 | 时间戳 |
| 举报类型 | 违规内容 / 侵权 / 社区秩序 / 交易风险 / 其他 |
| 被举报内容 | 内容摘要 + 链接，点击跳转查看 |
| 举报人 | 举报人昵称 |
| 被举报人 | 被举报用户昵称 |
| 状态 | 待处理 / 处理中 / 已处理 |

列表按举报时间升序排列（最早举报的优先处理）。

### N03.7.2 单条举报处理面板

点击某条举报后，右侧展开处理面板，包含：
- 举报基本信息（类型、举报人、被举报人、举报说明、证据截图）
- 处置方式单选（驳回举报 / 删除内容 / 下架作品 / 限制发帖评论 1 天 / 限制发帖评论 7 天 / 永久封禁账号）
- 处置说明（必填，200 字以内，记录处理依据）

**管理员操作约束**：
1. 处置说明必填，记录处理依据。
2. 所有处置操作写入审计日志（与加精操作日志分开管理）。
3. 管理员可同时处理被举报内容并对被举报人施加处罚。

### N03.7.3 AI 审查建议展示

在举报处理页面，若工单存在关联的 AI 建议（`ai_suggestion` 字段非空），则在工单项右侧展示"AI建议"标签，点击弹出详情弹窗。

**标签样式**：
- 文本为"AI建议：{action}"（如"AI建议：删除帖子"）
- 颜色：confidence ≥ 80 绿色，50-79 橙色，<50 灰色
- 若管理员已完成审批，标签变灰显示"已处理"，但仍可点击查看详情

**详情弹窗**：
- 展示字段：建议 Agent、建议操作、置信度（带进度条）、违规证据、匹配规则
- "决策轨迹"默认折叠，点击展开，最大高度 300px 可滚动
- 弹窗为模态窗口，关闭方式为点击蒙层或关闭按钮

前端实现需遵循设计令牌，颜色使用 `var(--color-success)`, `var(--color-warning)`, `var(--text-muted)` 等，进度条组件复用全局样式。

## N03.8 举报结果通知

管理员提交处理后，系统自动向举报人和被举报人发送通知，使用 `report_result` 事件（见附录 I03），渠道为 `in_app + email`。

### N03.8.1 通知接收人：举报人

| 处置结果 | 通知内容 |
| --- | --- |
| 举报成立（内容被处理） | 「你举报的{内容类型}已被处理。处理结果：{处置方式}。感谢你对社区秩序的维护。」 |
| 举报被驳回 | 「你举报的{内容类型}经审核未发现违规。如有疑问，可补充证据后重新提交。」 |

### N03.8.2 通知接收人：被举报人

| 处置结果 | 通知内容 |
| --- | --- |
| 内容被删除/下架 | 「你的{内容类型}因违反社区规范已被处理。处理原因：{处置说明}。如有异议，可在 7 天内提交申诉。」 |
| 账号被限制/封禁 | 「你的账号因违反社区规范已被{处置方式}。处理原因：{处置说明}。如有异议，可在 7 天内提交申诉。」 |

## N03.9 用户申诉

### N03.9.1 申诉入口

| 入口 | 位置 |
| --- | --- |
| 处罚通知中 | 通知卡片底部「提交申诉」按钮 |
| 设置页 | 「数据管理」→「我的处罚记录」→ 对应处罚记录「申诉」按钮 |

### N03.9.2 申诉表单字段规则

| 字段 | 必填 | 说明 |
| --- | :---: | --- |
| 申诉理由 | 是 | 500 字以内 |
| 补充证据 | 否 | 最多 5 张，每张 ≤ 5 MB |

只读展示字段：申诉对象、处罚类型、处罚时间、处罚原因（管理员处置说明）。

**提交后反馈**：Toast「申诉已提交，平台将在 3 个工作日内复核并通知结果」

### N03.9.3 申诉约束

| 规则 | 说明 |
| --- | --- |
| 申诉有效期 | 处罚后 7 天内 |
| 同一处罚的申诉次数 | 仅可提交 1 次 |
| 申诉结果 | 不可二次申诉，为最终决定 |
| 恶意申诉 | 管理员判定后可追加处罚 |

### N03.9.4 申诉处理与通知

管理员在后台「申诉处理」列表中复核，可选「维持原处罚」或「撤销处罚」，结果通过 `appeal_result` 事件（见附录 I03）通知申诉人。

| 处理结果 | 通知申诉人 |
| --- | --- |
| 维持原处罚 | 「你的申诉经复核后，维持原处罚决定。」 |
| 撤销处罚 | 「你的申诉经复核后，原处罚已撤销，相关内容已恢复。」 |
