## 使用方法

1. 将上述代码保存为 `icons.svg` 文件，放在项目的 `public/` 或 `assets/` 目录下。
    
2. 在 HTML 的 `<body>` 开头（或页面模板中）通过 `<object>` 或直接内联引入，但最方便的是**在页面中内联整个 SVG**（放在 `<div style="display: none;">` 中），这样所有图标都可以用 `<use>` 直接引用，无需额外 HTTP 请求。

用示例：

html
```
<svg width="20" height="20" aria-hidden="true">
  <use href="#icon-dice" />
</svg>
```
