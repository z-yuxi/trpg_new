# 文档对齐治理

## 1. 目的

统一维护 docs 与 docs/design 的上游准则优先级，避免在多个文档重复粘贴同一清单导致回填不一致。

## 2. 上游准则（按优先级）

1. `docs/附录 S：SVG 图标系统规范.md`
2. `docs/附录 B：设计令牌（Design Tokens）.md`
3. `docs/附录 D：设计系统.md`
4. `docs/首页视觉修正_设计交付包_v1.0.md`
5. `docs/附录Q_设计质量检查清单.md`
6. `docs/规则配方系统技术方案.md`

## 3. 适用范围

- 适用于 `docs/design` 下所有设计附录与主设计文档。
- 根目录 `docs` 的专题文档可引用本治理文档，不要求重复维护同一清单。

## 4. 冲突处理规则

- `docs/design` 文档与上游准则冲突时，以上游准则为准。
- `docs/design` 文档中的历史术语、旧示例、迁移说明，不得反向覆盖上游准则。
- 各文档可保留自身“职责边界/附加约束”段落，但不再重复内嵌六条准则清单。

## 5. 维护约定

- 上游准则列表增删或重排时，仅修改本文件。
- 其他文档只保留短引用声明（例如“遵循 docs/文档对齐治理.md”）。
- 文档评审时优先检查：引用是否存在、职责边界是否清晰、是否出现重复清单。
