## 二、设计师部分：SVG 图标 & 缺省插画

### 核心规范（必须遵守）

| 维度 | 要求 |
|------|------|
| **风格** | 简约线性，无填充、无渐变、无纹理 |
| **线条粗细** | 统一 `2px-2.5px` |
| **圆角** | 统一 `2px-4px` |
| **颜色** | 使用 `currentColor`，不硬编码颜色 |
| **尺寸** | 图标 `24x24` 和 `32x32` 两种 viewBox；插画 `400x300` viewBox |
| **动画** | 仅允许轻微微动画（±3px 浮动，2s 循环），禁止闪烁/旋转 |

### SVG 代码规范示例

```svg
<!-- icon-search-24.svg -->
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <circle cx="11" cy="11" r="8"/>
  <line x1="21" y1="21" x2="16.65" y2="16.65"/>
</svg>
```

**关键要求**：
- `stroke="currentColor"` → 允许 CSS 控制颜色
- `fill="none"` → 无填充，纯线条
- `stroke-width="2"` → 统一线条粗细
- `stroke-linecap="round"` → 圆角线端
- `stroke-linejoin="round"` → 圆角连接
