## 七、常见陷阱与注意事项

1. **不要只改 tokens.css，不改组件 CSS**  
   很多组件写了 `background: var(--bg-2, #f5f5f5)` 这种 fallback，即使 token 改对了，fallback 还是硬编码。必须清理所有 fallback。

2. **夜间模式的 `--color-primary` 不是浅灰**  
   v2.3.1 把夜间 `--color-primary` 改成了 Slate 200（`#e2e8f0`），这是错误的。夜间品牌色应该是**提亮蓝** `#6B9DC8`，而不是变成灰色。

3. **信息色 `--color-info` 与品牌色统一**  
   如果保留标准蓝 `#2563eb`，页面上会同时出现两种蓝色，破坏品牌一致性。建议统一为品牌蓝。

4. **RulesetEditor 需要独立变量**  
   如果规则编辑器确实需要深色画布主题，不要污染全局 `--color-primary`，应定义 `--rs-canvas-bg`、`--rs-panel-bg` 等独立变量。

5. **向后兼容别名设定期限**  
   `--tp-*` 旧变量保留 1 个月，2026-05-25 后全部移除，强制使用新语义命名。
