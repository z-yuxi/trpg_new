1. **数据库迁移** `packages/server/src/db/migrations/014_post_comment_system.ts`
   迁移文件使用 Knex 的 `schema.createTableIfNotExists` 或 `raw()` 方法。以下为 DDL（供参照）：

```sql
-- 主楼层表（对招募帖的直接回复），楼层号从 2 起（1 预留给帖子正文）
CREATE TABLE post_replies (
  id VARCHAR(64) PRIMARY KEY,
  post_id VARCHAR(64) NOT NULL,       -- 关联招募帖 ID（应用层校验存在性）
  user_id VARCHAR(64) NOT NULL,
  floor_number INT NOT NULL,          -- 物理存储，软删除后不变
  content TEXT NOT NULL,
  like_count INT DEFAULT 0,           -- 冗余计数，与 floor_likes 同一事务更新
  reply_count INT DEFAULT 0,          -- 冗余计数，与 reply_comments 同一事务更新
  is_original_post BOOLEAN DEFAULT FALSE,
  deleted BOOLEAN DEFAULT FALSE,      -- 软删除：TRUE 时显示"该楼层已删除"
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
  -- PostgreSQL 需另建 updated_at 触发器
);
-- 索引：INDEX idx_post_floor (post_id, floor_number)

-- 楼中楼表（单楼层下的二级评论，嵌套层数应用层限制为 1）
CREATE TABLE reply_comments (
  id VARCHAR(64) PRIMARY KEY,
  reply_id VARCHAR(64) NOT NULL,      -- 关联 post_replies.id
  user_id VARCHAR(64) NOT NULL,
  parent_comment_id VARCHAR(64) NULL, -- @提及用，不增加嵌套层数；校验不能指向本表中 reply_id 不同的记录
  content TEXT NOT NULL,
  like_count INT DEFAULT 0,
  deleted BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
-- 索引：INDEX idx_reply (reply_id, created_at)

-- 楼层点赞防重复
CREATE TABLE floor_likes (
  id VARCHAR(64) PRIMARY KEY,
  reply_id VARCHAR(64) NOT NULL,
  user_id VARCHAR(64) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_floor (reply_id, user_id)
);

-- 楼中楼点赞防重复
CREATE TABLE comment_likes (
  id VARCHAR(64) PRIMARY KEY,
  comment_id VARCHAR(64) NOT NULL,
  user_id VARCHAR(64) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_comment (comment_id, user_id)
);
```

   ```typescript
   // 函数签名（完整实现时参照 forum-service.ts 的代码风格）
   async function createFloor(postId: string, userId: string, content: string): Promise<FloorReply>
   // 楼层号 = SELECT MAX(floor_number)+1 FROM post_replies WHERE post_id=? → 至少为 2
   // 同一事务中不需要更新 reply_count（该字段在楼中楼时更新）

   async function deleteFloor(floorId: string, requestUserId: string): Promise<void>
   // 软删除：UPDATE post_replies SET deleted=true WHERE id=? AND user_id=?
   // GM 删除跳过 user_id 校验（需额外传入 isGm: boolean）

   async function createComment(replyId: string, userId: string, content: string, parentCommentId?: string): Promise<FloorComment>
   // 写入前校验：若 parentCommentId 存在，须确认其 reply_id === replyId（防跨楼嵌套）
   // 写入后：同一事务 UPDATE post_replies SET reply_count=reply_count+1 WHERE id=replyId

   async function deleteComment(commentId: string, requestUserId: string): Promise<void>
   // 物理删除；同步 UPDATE post_replies SET reply_count=reply_count-1

   async function likeFloor(replyId: string, userId: string): Promise<void>
   // INSERT INTO floor_likes; 冲突（UNIQUE）时忽略（409）
   // 同一事务 UPDATE post_replies SET like_count=like_count+1

   async function unlikeFloor(replyId: string, userId: string): Promise<void>
   // DELETE FROM floor_likes; 同步 UPDATE post_replies SET like_count=like_count-1

   async function likeComment(commentId: string, userId: string): Promise<void>
   async function unlikeComment(commentId: string, userId: string): Promise<void>

   async function getFloorsWithComments(postId: string, page: number, pageSize: number, requestUserId?: string): Promise<FloorsPageResponse>
   // 查询主楼层 + JOIN users 获取昵称和头像
   // 每楼附带最新 3 条楼中楼（子查询）
   // 若 requestUserId 存在，LEFT JOIN floor_likes 判断 is_liked_by_me

   async function getFloorComments(replyId: string, page: number, pageSize: number, requestUserId?: string): Promise<{ comments: FloorComment[]; total: number }>
   ```

## 开发规范提醒

1. **所有团名、场景名、用户昵称等**：严禁硬编码，必须从后端数据动态获取
2. **路由参数**：使用 `campaign_id`、`user_id` 等作为路由参数，不使用固定字符串
3. **错误处理**：API 调用使用 try/catch，用户可见错误使用 `ElMessage.error()`，开发日志使用 `console.error()`
4. **权限校验**：GM 专属功能须在前端（`isGm`）和后端（JWT + 数据库查询）双重校验
5. **Zod 校验**：所有 POST/PUT/PATCH 请求体必须使用 Zod schema 校验
6. **数据库迁移**：新迁移文件命名格式 `0XX_描述.ts`，使用幂等方式（`IF NOT EXISTS`）
7. **Socket 事件**：新事件名需同步添加到 `packages/shared/src/types/events.ts`
