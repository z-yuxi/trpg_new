# AI 开发视觉强制规范（开发 AI 必读）

> **优先级**：本文件的所有规则优先于 AI 自身的"默认审美判断"。
> **使用方式**：每次让 AI 编写/修改前端页面时，将本文件作为上下文注入。
> **关联文档**：附录 B（设计令牌）、附录 D（设计系统）、附录 Q（质量检查清单）

## 一、颜色锁定（禁止使用其他色值）

以下是唯一合法的颜色来源。**禁止使用 Tailwind 默认色板、Slate 灰阶、或任何 #3b82f6 类蓝色。**

```css
/* ===== 必须写入 tokens.css 的变量 ===== */

/* 品牌主色：雾霾蓝（不是 Tailwind Blue，不是 Slate） */
--color-primary: #5B8DB8;
--color-primary-hover: #4A7A9F;
--color-primary-active: #3D6A8F;
--color-primary-light: rgba(91, 141, 184, 0.12);

/* 夜间模式 */
--color-primary-dark: #6B9DC8;

/* 危险/强调色：灰红 */
--color-danger: #B85450;
--color-danger-hover: #A04743;

/* 功能色 */
--color-success: #6B8E6B;
--color-warning: #C9A227;

/* 灰阶（日间） */
--gray-100: #F5F7FA;   /* 页面背景 */
--gray-200: #E8ECF0;   /* 卡片边框 */
--gray-0: #FFFFFF;      /* 卡片背景 */
--gray-500: #667085;    /* 次要文字 */
--gray-900: #101828;    /* 标题文字 */
```

**验证方法**：代码中搜索 `#0f172a`、`#3b82f6`、`#2563eb`、`#334155`，如果找到，说明使用了错误的颜色。

## 二、空间层级系统（三层空间，逐层定义）

每个页面必须建立三层空间感。不是靠"阴影大小"区分，而是靠 **阴影 + 位移 + 透明度 + 背景处理** 的组合。

### 背景层（z-depth: 0）

用途：品牌氛围、装饰性内容。用户不需要与之交互。

```css
/* 首页 Hero Banner —— 降级为背景纹理 */
.hero-banner {
  background: linear-gradient(135deg, #5B8DB8 0%, #4A7A9F 50%, #3D6A8F 100%);
  border-radius: 12px;
  padding: 32px 24px;
  position: relative;
  overflow: hidden;
}

/* 装饰：淡色网格 */
.hero-banner::before {
  content: '';
  position: absolute;
  inset: 0;
  background-image:
    linear-gradient(rgba(255,255,255,0.06) 1px, transparent 1px),
    linear-gradient(90deg, rgba(255,255,255,0.06) 1px, transparent 1px);
  background-size: 40px 40px;
  pointer-events: none;
}

/* 装饰：右上角圆环 */
.hero-banner::after {
  content: '';
  position: absolute;
  top: -30%;
  right: -15%;
  width: 250px;
  height: 250px;
  border: 2px solid rgba(255,255,255,0.08);
  border-radius: 50%;
  pointer-events: none;
}
```

**规则**：Banner 内的文字为白色（`rgba(255,255,255,0.9)`），Banner 本身不是内容主体，高度不超过 160px。

### 中景层（z-depth: 1）

用途：导航、Tab 栏、面包屑、筛选栏。为用户提供上下文切换能力。

```css
/* 顶部导航栏 —— 毛玻璃效果 */
.top-bar {
  background: rgba(255, 255, 255, 0.85);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
  border-bottom: 1px solid rgba(232, 236, 240, 0.8);
  position: sticky;
  top: 0;
  z-index: 100;
}

/* 筛选栏 */
.filter-bar {
  background: var(--gray-0);
  border: 1px solid var(--gray-200);
  border-radius: 8px;
  padding: 8px 12px;
  box-shadow: 0 1px 2px rgba(16, 24, 40, 0.05);
}

/* Tab 切换按钮（选中态） */
.tab-active {
  background: var(--color-primary);
  color: white;
  border-radius: 9999px;
  box-shadow: 0 1px 3px rgba(91, 141, 184, 0.3);
}
```

### 前景层（z-depth: 2-3）

用途：用户当前核心任务。卡片、操作区域。

```css
/* 普通卡片 —— z-depth: 2 */
.card {
  background: var(--gray-0);
  border: 1px solid var(--gray-200);
  border-radius: 8px;
  box-shadow: 0 1px 3px rgba(16, 24, 40, 0.08);
  transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
}

/* 重要/活跃卡片 —— z-depth: 3（如"进行中的团"） */
.card-elevated {
  box-shadow: 0 4px 12px rgba(16, 24, 40, 0.12);
  transform: translateY(-2px);
}

/* 已结束/非活跃卡片 —— 视觉沉底 */
.card-recessed {
  opacity: 0.65;
  box-shadow: none;
  filter: saturate(0.7);
}
```

### 首页布局的层级权重分配

```
┌─────────────────────────────────────────┐
│ [背景] Hero Banner（渐变纹理，160px）    │  ← 氛围，不可交互
├─────────────────────────────────────────┤
│ [前景-高权重] 进行中的团                  │  ← 大卡片，阴影浮起
│   ┌───────┐ ┌───────┐ ┌───────┐        │     用户高频查看
│   │ 团A   │ │ 团B   │ │ 团C   │        │
│   └───────┘ └───────┘ └───────┘        │
├─────────────────────────────────────────┤
│ [前景-低权重] 快速组队                    │  ← 小卡片/描边风格
│   ┌─ ─ ─ ─┐ ┌─ ─ ─ ─┐ ┌─ ─ ─ ─┐     │     用户低频但重要
│   │找团玩  │ │当 KP  │ │发求组帖│      │     用虚线边框区分
│   └─ ─ ─ ─┘ └─ ─ ─ ─┘ └─ ─ ─ ─┘     │
├─────────────────────────────────────────┤
│ [中景] 热门规则集 / 最新动态              │  ← 标准权重
└─────────────────────────────────────────┘
```

**关键区分**："进行中的团"和"快速组队"绝对不能用相同的卡片样式。前者用实线边框+阴影浮起，后者用虚线边框+无阴影+品牌色图标。

## 三、状态视觉隐喻（不看文字即可感知）

**禁止仅用右上角小色块标签表示状态。** 必须通过卡片整体形态传达。

### 状态到视觉的映射表

| 状态 | 左边框 | 卡片阴影 | 透明度 | 特殊效果 | CSS class |
|------|--------|---------|--------|---------|-----------|
| 进行中 | `3px solid #6B8E6B` | `shadow-md` | 1.0 | 脉冲绿点 | `.status-running` |
| 准备中 | `3px dashed #C9A227` | `shadow-sm` | 1.0 | 无 | `.status-preparing` |
| 已暂停 | `3px dashed #98A2B3` | 无 | 0.75 | 无 | `.status-paused` |
| 已结束 | `3px solid #98A2B3` | 无 | 0.65 | 去饱和 | `.status-ended` |

### 具体 CSS

```css
/* 进行中 —— 活跃感 */
.status-running {
  border-left: 3px solid #6B8E6B;
  box-shadow: 0 4px 12px rgba(16, 24, 40, 0.1);
}

.status-running .status-dot {
  width: 8px;
  height: 8px;
  background: #6B8E6B;
  border-radius: 50%;
  animation: pulse 2s ease-in-out infinite;
}

@keyframes pulse {
  0%, 100% { opacity: 1; transform: scale(1); }
  50% { opacity: 0.5; transform: scale(1.3); }
}

/* 准备中 —— 未完成感 */
.status-preparing {
  border-left: 3px dashed #C9A227;
  box-shadow: 0 1px 3px rgba(16, 24, 40, 0.06);
}

/* 已暂停 */
.status-paused {
  border-left: 3px dashed #98A2B3;
  opacity: 0.75;
  box-shadow: none;
}

/* 已结束 —— 归档感 */
.status-ended {
  border-left: 3px solid #98A2B3;
  opacity: 0.65;
  filter: saturate(0.7);
  box-shadow: none;
}
```

**应用位置**：这些 class 加在 `<TCard>` 的外层 wrapper 上，不修改 TCard 组件本身。

## 四、交互反馈规范（所有可点击元素必须遵守）

### 卡片

```css
.card-interactive {
  transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
  cursor: pointer;
}

/* 悬停：抬起 */
.card-interactive:hover {
  transform: translateY(-3px);
  box-shadow: 0 8px 24px rgba(16, 24, 40, 0.12);
}

/* 按压：下沉 */
.card-interactive:active {
  transform: translateY(0) scale(0.98);
  box-shadow: 0 2px 4px rgba(16, 24, 40, 0.1);
}

/* 键盘焦点 */
.card-interactive:focus-visible {
  outline: none;
  box-shadow: 0 0 0 3px rgba(91, 141, 184, 0.3);
}
```

### 按钮

```css
.t-btn {
  transition: all 0.15s cubic-bezier(0.4, 0, 0.2, 1);
}

.t-btn:hover:not(:disabled) {
  transform: scale(1.02);
}

.t-btn:active:not(:disabled) {
  transform: scale(0.96);
}
```

### 导航项

```css
.nav-item {
  position: relative;
  transition: color 0.2s ease;
}

/* 选中态下划线（滑入动画） */
.nav-item.active::after {
  content: '';
  position: absolute;
  bottom: 0;
  left: 50%;
  transform: translateX(-50%);
  width: 20px;
  height: 2px;
  background: var(--color-primary);
  border-radius: 1px;
  animation: slideIn 0.2s ease;
}

@keyframes slideIn {
  from { width: 0; opacity: 0; }
  to { width: 20px; opacity: 1; }
}
```

## 五、招募板信息密度规范

招募帖**禁止**使用全宽单列列表。必须使用紧凑卡片网格。

### 布局

```css
.recruitment-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);  /* 移动端 1 列 */
  gap: 12px;
}

@media (max-width: 480px) {
  .recruitment-grid {
    grid-template-columns: 1fr;
  }
}
```

### 单张招募卡片结构

```
┌──────────────────────────┐
│ [招募中]        CoC 7e   │  ← 状态徽章 + 规则集标签
│                          │
│ 深渊的呼唤                │  ← 标题，单行截断
│                          │
│ 👤 GM：夜行者            │  ← 左对齐 icon + 文字
│ 👥 玩家：3/5             │  ← 含进度条
│ 📅 每周六 20:00          │
│ 🎭 线上 · 文字团          │
│                          │
│ [查看详情]               │  ← 底部操作
└──────────────────────────┘
```

**关键**：用户扫一眼（<2 秒）必须能判断"这个团我感不感兴趣"。所以 GM 名称、规则集、时间、人数必须在不滚动的情况下全部可见。

## 六、AI 执行检查清单

每次修改完页面后，AI 必须自查：

- [ ] `tokens.css` 中 `--color-primary` 是 `#5B8DB8` 不是 `#0f172a` 或 `#3b82f6`
- [ ] 页面是否有三层空间感（背景纹理、中景导航、前景卡片）
- [ ] "进行中"的卡片是否比"准备中"更突出（阴影更大、位置更高）
- [ ] 不看文字标签，仅看卡片外形能否区分四种状态
- [ ] 所有卡片 hover 时是否有 `translateY` + 阴影变化
- [ ] 所有按钮 hover 时是否有视觉反馈
- [ ] 按钮按下时是否有 `scale` 缩小反馈
- [ ] 招募帖是否为多列网格（不是全宽列表）
- [ ] 没有使用任何硬编码颜色值（搜索 `#` 开头的 6 位色值）
