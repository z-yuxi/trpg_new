

> **适用版本**：V3.0 及后续迭代  
> **核心原则**：功能不减、交互重塑、手势优先、渐进增强  
> **平台**：PWA（可安装至桌面），需支持 iOS Safari 和 Android Chrome

## 一、整体布局适配

| 元素 | 桌面端 | 移动端 |
|------|--------|--------|
| **底部导航** | 5个文字+图标（高度48px） | 5个图标+隐藏文字（长按显示标签），高度56px，触摸热区≥44px |
| **页面内边距** | 24px | 16px |
| **卡片/网格** | 多列响应式（4列→2列） | 默认2列，列表项高度≥56px |
| **筛选栏** | 多行横向排列 | 顶部显示2-3个主要筛选项，其余折叠入“更多筛选”底部抽屉 |
| **模态框** | 居中弹窗（宽≤500px） | 全屏底部抽屉（可从下滑关闭），圆角顶部16px |

## 二、跑团房间移动端专属布局

跑团房间是移动端最复杂的页面，需重新设计为**底部快捷栏 + 抽屉面板**模式。

```
┌─────────────────────────────────┐
│ [←] 房间名     👥3  ☀️ [GM] [≡] │ ← 顶部栏（汉堡菜单、GM控制台入口）
├─────────────────────────────────┤
│ [剧情场] [私密场] [公共场]        │ ← 聊天场Tab（可横向滑动）
├─────────────────────────────────┤
│                                 │
│  聊天消息区（气泡）               │
│  - 普通消息：左/右气泡            │
│  - 骰子结果：卡片样式             │
│  - 线索揭示：卡片，点击展开        │
│                                 │
├─────────────────────────────────┤
│ [输入框]                    [📎]│ ← 输入区
├─────────────────────────────────┤
│ [🎲] [角色卡] [指令] [更多]       │ ← 底部快捷栏（固定4个按钮）
└─────────────────────────────────┘
```

**底部快捷栏功能**：
- `[🎲]`：展开骰子快捷面板（预设常用指令，如 .ra 侦查、.r 1d100）
- `[角色卡]`：弹出半屏抽屉，显示当前角色卡摘要（头像、姓名、HP条、核心属性），点击“编辑”展开完整角色卡表单
- `[指令]`：弹出半屏指令速查列表，点击指令自动填入输入框
- `[更多]`：弹出底部动作表单，包含“投骰历史”、“切换身份”、“退出房间”等

**顶部栏右侧按钮**：
- `[GM]`（仅GM可见）：打开GM控制台（底部动作表单，分页展示）
- `[≡]`：打开左侧导航抽屉（场景列表、轨迹矩阵精简版、在场角色）

## 三、关键组件移动端行为

| 组件 | 桌面端行为 | 移动端适配 |
|------|------------|------------|
| **左侧导航（场景列表）** | 固定侧边栏（240px） | 汉堡菜单 → 滑出半屏抽屉（宽度85%），点击项后关闭 |
| **右侧助理台** | 固定侧边栏（320px） | 移除固定面板，功能移至底部快捷栏（见上文） |
| **GM控制台** | 顶部下拉面板（200px） | 底部动作表单，分页：时间控制 / 场景管理 / NPC控制 / 线索库 / 高级（轨迹矩阵、网格地图入口） |
| **轨迹矩阵（完整版）** | 灰白分区表格，横向+纵向滚动 | **改为时间轴视图**（见第四章） |
| **网格地图（Token移动）** | Canvas拖拽Token | **降级为静态地图+坐标列表移动**（见第四章） |
| **规则工坊L3画布** | 拖拽节点连线 | 不可用，提示“请在PC端编辑”，移动端只读查看已发布规则 |
| **模组编辑器（文档式块）** | 块编辑器 | 不可用，提示“请在PC端编辑”，移动端只读查看已发布模组内容 |
| **可视化拖拽编辑器（日志导出）** | 拖拽排序场景块 | 不可用，提示“请在PC端使用”，移动端仅支持基础导出（TXT/Markdown） |

## 四、会员专属功能的移动端适配

### 4.1 轨迹矩阵（会员功能）

**桌面端**：横向时间轴 + 纵向场景列表，单元格显示角色头像，支持点击查看快照。

**移动端适配**：改为**时间轴视图 + 场景筛选**

- **默认视图**：垂直时间轴，按时间倒序排列，每条节点显示：
  - 时间（如“第1日 15:30”）
  - 该时刻发生的场景切换事件摘要（如“张三 进入 图书馆”）
  - 可点击展开查看该时刻所有场景的角色位置快照（以卡片列表展示）
- **场景筛选**：顶部下拉选择特定场景，时间轴只显示该场景的角色位置变化。
- **GM操作**：长按时间节点弹出动作菜单（强制移动、调整时间），不支持单元格拖拽。

**技术实现**：使用虚拟滚动列表渲染时间轴，快照数据按需加载。桌面端的表格视图仍保留，移动端自动切换为时间轴（响应式判断 `max-width: 768px`）。

### 4.2 网格地图（会员功能）

**桌面端**：Canvas网格，支持拖拽Token、上传底图、多图层。

**移动端适配**：降级为**静态地图预览 + 坐标列表移动**

- **默认视图**：显示当前场景的地图缩略图（图片），不可拖拽Token。
- **角色位置**：地图旁显示角色列表，每个角色后跟坐标（如“A3”）。
- **移动操作（仅GM）**：点击角色 → 弹出简化网格选择器（9宫格或列表选择目标格子） → 确认后更新位置。
- **可选高级模式**：用户可开启“精细模式”（提示性能消耗），使用Canvas网格并支持双指缩放、单击选中角色后点击网格移动（非拖拽）。

**技术实现**：地图数据存储为图片+网格配置（行列数、格子尺寸）。移动端默认只读，编辑操作通过表单完成。高级模式需用户主动开启。

## 五、手势与触摸规范

| 手势 | 用途 | 适用场景 |
|------|------|----------|
| **点击** | 选中、打开、提交 | 所有按钮、卡片、列表项 |
| **长按（≥500ms）** | 打开上下文菜单 | 房间卡片（管理）、消息（举报）、时间轴节点（GM操作） |
| **左滑** | 删除/归档 | 通知列表、私信会话 |
| **右滑** | 返回上一页 | 全屏抽屉、详情页 |
| **双指缩放** | 放大查看 | 地图、图片、复杂图表（如轨迹矩阵时间轴） |
| **下拉刷新** | 刷新列表 | 招募板、动态、消息列表 |

> **注意**：避免与系统手势冲突（如iOS左滑返回）。在边缘区域保留系统手势。

## 六、性能与体验优化

| 优化项 | 策略 |
|--------|------|
| **懒加载** | 聊天消息按需加载（每次20条），滚动顶部加载更多；轨迹矩阵时间轴虚拟滚动 |
| **网络不稳定** | WebSocket自动重连，断线时显示顶部横幅“连接中...”，重连后拉取缺失消息（通过 `missed_messages` 事件） |
| **后台保活** | PWA使用Service Worker缓存静态资源；跑团房间心跳保持（每30秒ping），但移动端允许后台断开，重连后同步 |
| **资源压缩** | 地图图片自动压缩为WebP，头像使用CDN且尺寸自适应（?x-oss-process=image/resize,w_200） |
| **触感反馈** | 关键操作（发送消息、掷骰、创建房间）使用轻震动（仅Android，需用户授权） |

## 七、移动端功能降级原则

移动端对部分桌面端复杂功能采用降级策略，核心原则如下：

|功能类型|降级方式|基本要求|
|---|---|---|
|**复杂编辑工具**（规则工坊画布、模组编辑器、可视化日志编辑器）|完全禁用或只读浏览|编辑入口隐藏或置灰；若保留查看能力，隐藏所有编辑控件|
|**空间操作工具**（网格地图、轨迹矩阵、场景连通配置）|简化交互|将拖拽/画布操作改为表单/列表选择；核心数据仍可查看和修改|
|**数据可视化图表**（创作者后台统计图）|降级为表格|用纯数字表格替代图形化图表|

**通用交互要求**：

- 禁用功能点击时，使用 Toast 提示引导至 PC 端，文案统一为“请在电脑上使用此功能”。
    
- 只读视图需保留核心信息展示，不得因降级导致数据丢失或不可见。
    
- 简化交互模式下，首次进入时可使用轻提示说明当前限制（如“移动端已切换为时间轴视图”），用户理解后不再重复提示。
    

具体各功能的降级行为由前端根据上述原则自行设计，本文档不再逐一规定。

## 八、测试与兼容性要求

| 平台 | 最低版本 | 测试重点 |
|------|----------|----------|
| iOS Safari | iOS 14+ | 底部安全区（刘海）、WebSocket重连、Canvas性能 |
| Android Chrome | Chrome 90+ | 震动API、PWA安装、后台保活 |
| 微信内置浏览器 | 最新版 | 支付回调、文件上传（地图图片） |

**响应式断点**：
- 桌面端：`≥ 1024px`
- 平板：`768px - 1023px`（可使用桌面端布局，但触摸热区加大）
- 移动端：`< 768px`

## 九、总结

移动端适配不是简单地将桌面端缩小，而是**重新设计交互模型**以适应触摸、小屏幕和移动网络环境。本指南明确了：

- **保留核心跑团体验**（聊天、掷骰、角色卡）
- **高级功能降级但可用**（轨迹矩阵改为时间轴，网格地图改为坐标移动）
- **复杂编辑功能引导至PC端**（规则工坊、模组编辑器）
- **性能与网络策略**确保流畅使用

前端开发应严格遵循本指南，并在必要时与产品确认交互细节。
